## 6.1 벡터공간과 선형독립

- 벡터공간은 두 가지로 나뉜다.
  - **실벡터공간(real vector space)**: 스칼라를 실수 전체 $R$로 택한 경우. "$R$ 위의 벡터공간"
  - **복소벡터공간(complex vector space)**: 스칼라를 복소수 전체 $C$로 택한 경우
  - 이 책에서는 **실벡터공간**만 다룬다.
- 복소수(complex number): 두 실수 $a, b$ 로 $a + bi$ 꼴로 이루어진 수. $i^2 = -1$, 즉 $i = \sqrt{-1}$

### 6.1.1 벡터공간과 부분공간

- **정의 6-1 (벡터공간)**: $V$가 벡터의 합과 스칼라 곱이 정의되는 공집합이 아닌 집합이고, $V$ 안의 모든 벡터 $\mathbf{u}, \mathbf{v}, \mathbf{w}$ 와 모든 스칼라 $\alpha, \beta$ 에 대해 다음 **10가지 공리(axioms)** 를 만족하면 $V$를 **벡터공간(vector space)** 이라 한다.

| # | 공리 | 이름 |
|---|---|---|
| 1 | $\mathbf{u} + \mathbf{v} \in V$ | **덧셈에 대해 닫혀있다** |
| 2 | $\mathbf{u} + \mathbf{v} = \mathbf{v} + \mathbf{u}$ | 덧셈에 대한 교환법칙 |
| 3 | $(\mathbf{u} + \mathbf{v}) + \mathbf{w} = \mathbf{u} + (\mathbf{v} + \mathbf{w})$ | 덧셈에 대한 결합법칙 |
| 4 | $\mathbf{u} + \mathbf{0} = \mathbf{u}$ 인 $\mathbf{0}$가 $V$에 존재 | 영벡터의 존재 |
| 5 | $\mathbf{u} + (-\mathbf{u}) = \mathbf{0}$ 인 $-\mathbf{u}$ 존재 | 덧셈에 대한 역원 |
| 6 | $\alpha\mathbf{u} \in V$ | **스칼라 곱에 대해 닫혀있다** |
| 7 | $\alpha(\mathbf{u} + \mathbf{v}) = \alpha\mathbf{u} + \alpha\mathbf{v}$ | 스칼라 곱에 대한 배분법칙 |
| 8 | $(\alpha + \beta)\mathbf{u} = \alpha\mathbf{u} + \beta\mathbf{u}$ | 스칼라 곱에 대한 배분법칙 |
| 9 | $\alpha(\beta\mathbf{u}) = (\alpha\beta)\mathbf{u}$ | 스칼라 곱에 대한 결합법칙 |
| 10 | $1\mathbf{u} = \mathbf{u}$ | 1은 스칼라 곱의 항등원 |

- 이 중 **가장 중요한 것**은 두 가지 "닫혀있음" 성질이다.
  1. $\mathbf{u}, \mathbf{v}$ 의 합 $\mathbf{u} + \mathbf{v}$ 도 $V$에 속한다. (덧셈에 대해 닫혀있다)
  2. $\mathbf{u}$에 스칼라 $\alpha$를 곱한 $\alpha\mathbf{u}$ 도 $V$에 속한다. (스칼라 곱에 대해 닫혀있다)
- 예제 6-1, 6-2: $R^3$, $R^n$ 은 실수 $R$ 위의 벡터공간이다(합과 스칼라 곱의 결과가 다시 $R^n$에 속함).
- **정의 6-2**: 하나의 원소 $\mathbf{0}$ 로만 이루어진 공간을 **영벡터공간(zero vector space)** 이라 한다. $\mathbf{0} + \mathbf{0} = \mathbf{0}$, $\alpha\mathbf{0} = \mathbf{0}$
- **정리 6-1**: 벡터공간 $V$의 원소 $\mathbf{u}$와 스칼라 $\alpha$ 에 대해
  1. $0\mathbf{u} = \mathbf{0}$
  2. $\alpha\mathbf{0} = \mathbf{0}$
  3. $(-1)\mathbf{u} = -\mathbf{u}$
  4. $\alpha\mathbf{u} = \mathbf{0}$ 이면 $\alpha = 0$ 또는 $\mathbf{u} = \mathbf{0}$

#### 부분공간

- **정의 6-3**: 벡터공간 $V$의 부분집합 $W$가 $V$에서 정의된 두 연산을 만족해(벡터의 합과 스칼라 곱에 대해 닫혀 있어) 새로운 벡터공간을 이루면, $W$를 $V$의 **부분공간(subspace)** 이라 한다.
  1. $\mathbf{u} \in W$ 이고 $\mathbf{v} \in W$ 이면 $\mathbf{u} + \mathbf{v} \in W$
  2. $\mathbf{u} \in W$ 이고 $\alpha$가 스칼라면 $\alpha\mathbf{u} \in W$
- **예제 6-3**: $S = \{(x, y, z) \mid x = y\}$ → 합과 스칼라 곱에서 첫째·둘째 성분이 계속 같다 → $R^3$의 **부분공간 O**
- **예제 6-4**: $W = \{(u_1, u_2, 1)\}$ → $\mathbf{u} + \mathbf{v}$ 의 셋째 성분이 2가 된다 → **부분공간 X**
- **예제 6-5**: $R^2$의 **제1사분면** 벡터들의 집합 → 합에는 닫혀 있지만 음수를 곱하면 제3사분면으로 간다 → 스칼라 곱에 닫혀 있지 않으므로 **부분공간 X**
- **예제 6-6**: 벡터 $\mathbf{v}_1, \dots, \mathbf{v}_n$ 의 **선형결합 전체 집합** $W = \{\alpha_1\mathbf{v}_1 + \cdots + \alpha_n\mathbf{v}_n\}$ 은 부분공간이다.
- **예제 6-7**: $AX = B$ 의 해집합은 $B = \mathbf{0}$ (동차)일 때만 $R^n$의 부분공간이다. $B \neq \mathbf{0}$ 이면 $A(X + Y) = 2B$ 가 되어 닫혀 있지 않다.

[보충] 부분공간 판별의 가장 빠른 첫 단계는 **영벡터가 포함되는지** 확인하는 것이다. 부분공간은 반드시 $\mathbf{0}$를 포함해야 한다($0\mathbf{u} = \mathbf{0}$ 이므로). 예제 6-4의 $W$는 셋째 성분이 항상 1이라 $\mathbf{0}$가 없으므로 바로 부분공간이 아님을 알 수 있다. $R^2$의 부분공간은 $\{\mathbf{0}\}$, 원점을 지나는 직선, $R^2$ 전체뿐이다.

### 6.1.2 선형독립과 선형종속

- **정의 6-4 (선형결합)**: 벡터 $\mathbf{v}_1, \dots, \mathbf{v}_n$ 과 스칼라 $a_1, \dots, a_n$ 에 대해 $a_1\mathbf{v}_1 + a_2\mathbf{v}_2 + \cdots + a_n\mathbf{v}_n$ 을 $\mathbf{v}_1, \dots, \mathbf{v}_n$ 의 **선형결합(linear combination)** 이라 한다.
- **예제 6-8**: $\mathbf{v}_1 = (1,2,1), \mathbf{v}_2 = (1,0,2), \mathbf{v}_3 = (1,1,0)$, $\mathbf{v} = (2,1,5)$
  - $a_1\mathbf{v}_1 + a_2\mathbf{v}_2 + a_3\mathbf{v}_3 = \mathbf{v}$ 를 가우스-조단으로 풀면 $a_1 = 1, a_2 = 2, a_3 = -1$ → $\mathbf{v} = \mathbf{v}_1 + 2\mathbf{v}_2 - \mathbf{v}_3$
- **정의 6-5 (선형종속 / 선형독립)**: 벡터 $\mathbf{v}_1, \dots, \mathbf{v}_n$ 에 대해

$$
a_1\mathbf{v}_1 + a_2\mathbf{v}_2 + \cdots + a_n\mathbf{v}_n = \mathbf{0}
$$

  - **적어도 하나는 0이 아닌** 상수 $a_i$로 이 식을 만족할 수 있으면 → **선형종속(linearly dependent)**
  - 이 식을 만족하는 상수가 **$a_1 = a_2 = \cdots = a_n = 0$ 뿐**이면 → **선형독립(linearly independent)**
- **정의 6-6 (선형종속의 다른 표현)**: $R^n$에서 벡터들 중 **최소한 하나의 벡터가 나머지 벡터들의 선형결합으로 표현될 수 있으면** 선형종속이다.
  - 예: $\mathbf{u} = (1, -3)$, $\mathbf{v} = (-2, 6)$ → $\mathbf{v} = -2\mathbf{u}$ → 선형종속

#### 예제

- **예제 6-9**: $\mathbf{u} = (1, 2), \mathbf{v} = (3, -5)$ → $a_1 + 3a_2 = 0,\ 2a_1 - 5a_2 = 0$ → $-11a_2 = 0$ → $a_1 = a_2 = 0$ → **선형독립**
- **예제 6-10**
  - (1) $\mathbf{u} = (1,1), \mathbf{v} = (1,0)$ → $a_1 = a_2 = 0$ → 선형독립
  - (2) $\mathbf{u} = (1,1), \mathbf{v} = (1,0), \mathbf{w} = (2,3)$ → $a_1 = 3, a_2 = -1, a_3 = -1$ 도 해 → **선형종속**. $3\mathbf{u} - \mathbf{v} - \mathbf{w} = \mathbf{0}$, 즉 $\mathbf{w} = 3\mathbf{u} - \mathbf{v}$
- **예제 6-11 (기하학적 해석)**
  - $R^2$: 두 벡터가 **겹치면**(같은 직선 위) 한 벡터가 다른 벡터의 배수 → 선형종속 / 겹치지 않으면 → 선형독립
  - $R^3$: $\mathbf{v}_3 = 2\mathbf{v}_1 + 3\mathbf{v}_2$ 처럼 세 벡터가 **한 평면 위**에 있으면 → 선형종속 / $\mathbf{v}_3$ 가 그 평면 밖에 있으면 → 선형독립
- **예제 6-12**: $(1,2,3), (2,5,7), (1,3,6)$ → 역대입으로 $a_1 = a_2 = a_3 = 0$ → 선형독립
- **예제 6-13**: $(1,0,0), (0,1,0), (0,0,1)$ → 세 단위벡터는 선형독립
- **예제 6-14**: $\mathbf{v}_1 = (0,1,0), \mathbf{v}_2 = (0,1,1), \mathbf{v}_3 = (0,0,1)$ → $a_1 = -a_2 = a_3$ 이면 되므로 모두 0일 필요가 없다 → **선형종속** (별해: $\mathbf{v}_1 + \mathbf{v}_3 = \mathbf{v}_2$)
- **예제 6-15**: $(1,0,0), (0,1,0), (3,1,0)$ → $a_1 = 3, a_2 = 1, a_3 = -1$ → 선형종속. 세 벡터가 모두 $xy$평면($R^2$) 위에 있다.

#### 선형종속인 경우 요약 (영벡터인 경우 제외)

1. $R^2$에서 두 벡터가 같은 직선 위에 있거나 평행한 경우
2. $R^2$에서 **3개 이상**의 벡터가 있는 경우
3. $R^2$에서 3개 중 2개 이상이 같은 직선 위에 있거나 평행한 경우
4. $R^3$에서 3개 중 어느 한 벡터를 다른 2개의 선형결합으로 나타낼 수 있는 경우

[보충] 일반화: $R^n$에서 **$n$개보다 많은** 벡터는 항상 선형종속이다. 또 **영벡터를 포함한** 벡터 집합은 항상 선형종속이다($1 \cdot \mathbf{0} = \mathbf{0}$). $n$개의 벡터가 $R^n$에 있을 때는 그 벡터들을 열로 하는 행렬 $A$에 대해 **$\det(A) \neq 0$ ⟺ 선형독립**으로 빠르게 판별할 수 있다.

## 6.2 생성, 기저, 차원

### 6.2.1 생성

- **정의 6-7**: 벡터공간 $V$의 모든 벡터를 $\mathbf{v}_1, \dots, \mathbf{v}_n$ 의 선형결합으로 나타낼 수 있으면, $\mathbf{v}_1, \dots, \mathbf{v}_n$ 이 $V$를 **생성(span, 生成)** 한다고 한다.
  - 즉 모든 $\mathbf{v} \in V$ 에 대해 $a_1\mathbf{v}_1 + \cdots + a_n\mathbf{v}_n = \mathbf{v}$ 를 만족하는 스칼라가 존재하는 경우
- **예제 6-16**: $\mathbf{v}_1 = (2, 4), \mathbf{v}_2 = (-1, 2)$
  - 임의의 $(a, b)$ 에 대해 $2a_1 - a_2 = a,\ 4a_1 + 2a_2 = b$ → $a_1 = \frac{2a+b}{8}$, $a_2 = \frac{-2a+b}{4}$ 가 존재 → $R^2$을 **생성**
- **예제 6-17**: $\mathbf{v}_1 = (1,2,1), \mathbf{v}_2 = (1,0,2), \mathbf{v}_3 = (1,1,0)$
  - $a_1 = \frac{-2a+2b+c}{3}$, $a_2 = \frac{a-b+c}{3}$, $a_3 = \frac{4a-b-2c}{3}$ → $R^3$을 생성
- 판별 방법 정리
  - **선형독립**: 선형결합 $= \mathbf{0}$ 으로 놓고 풀어서 계수가 모두 0인지 확인
  - **생성**: 임의의 벡터 $(a, b, \dots)$ 가 주어진 벡터들의 선형결합으로 만들어지는지(계수가 존재하는지) 확인

### 6.2.2 기저

- **정의 6-8**: 벡터공간 $V$의 벡터 $\mathbf{v}_1, \dots, \mathbf{v}_n$ 이 다음 두 조건을 **동시에** 만족하면 $\{\mathbf{v}_1, \dots, \mathbf{v}_n\}$ 을 $V$의 **기저(basis, 基底)** 라 한다.
  1. $\mathbf{v}_1, \dots, \mathbf{v}_n$ 이 **선형독립**이다.
  2. $\mathbf{v}_1, \dots, \mathbf{v}_n$ 이 $V$를 **생성**한다.
- 기저를 이루는 벡터들은 영벡터가 아니어야 하고, 최소한 서로 달라야 한다.
- 다르게 표현하면: 모든 $\mathbf{v} \in V$ 에 대해 $a_1\mathbf{v}_1 + \cdots + a_n\mathbf{v}_n = \mathbf{v}$ 인 스칼라 해가 **꼭 1세트만** 존재하는 경우다.
- **예제 6-18**: $(1, 0), (0, 1)$ → 선형독립 + $R^2$ 생성($a_1 = a, a_2 = b$) → $R^2$의 기저
- **예제 6-19**: $(1,1,1), (1,1,0), (1,0,0)$ → 선형독립 + 생성($a_1 = c, a_2 = b - c, a_3 = a - b$) → $R^3$의 기저
- **예제 6-20**: (1) $(-1,0,0), (0,1,0), (-2,2,3)$ → $R^3$의 기저 O / (2) $(1,0), (0,1)$ → $R^2$의 기저 O / (3) $(1,0), (0,1), (1,3)$ → 3개가 모두 $R^2$ 위에 있으므로 기저 X (선형종속)
- **정의 6-9 (표준기저)**: $R^3$에 대해 $\mathbf{i} = (1,0,0), \mathbf{j} = (0,1,0), \mathbf{k} = (0,0,1)$ 을 **표준기저(standard basis)** 또는 **자연기저(natural basis)** 라 한다.
  - 임의의 $\mathbf{v} = (a_1, a_2, a_3) = a_1\mathbf{i} + a_2\mathbf{j} + a_3\mathbf{k}$
  - $R^n$의 표준기저 $\{\mathbf{e}_1, \dots, \mathbf{e}_n\}$: $\mathbf{e}_i$ 는 $i$번째 행만 1이고 나머지는 0인 $n \times 1$ 행렬
- **예제 6-21**: $(1,0,0), (0,0,1)$ → 선형독립이지만 둘째 성분이 모두 0이라 $R^3$을 **생성하지 못함** → 기저 X
- **예제 6-22**: $(1,1), (2,3), (1,0)$ → 선형종속($a_1 = -3, a_2 = 1, a_3 = 1$)이지만 $R^2$을 **생성함** → 기저 X. 3개 중 아무 2개만 골라도 $R^2$을 생성한다.

| 경우 | 예 | 기저? |
|---|---|---|
| 선형독립 O, 생성 X | $R^3$에 벡터 2개 (예제 6-21) | X |
| 선형독립 X, 생성 O | $R^2$에 벡터 3개 (예제 6-22) | X |
| 선형독립 O, 생성 O | 예제 6-18, 6-19 | **O** |

### 6.2.3 차원

- **정의 6-10**: $V$가 $R^n$의 벡터공간일 때, $V$의 **기저가 되는 벡터의 개수**를 **차원(dimension)** 이라 하고 $\dim(V)$ 로 쓴다.
  - 영벡터로 이루어진 벡터공간의 차원은 0이다.
  - $V$가 유한 기저를 가지면 $\dim(V) = n$
- **예제 6-23**: $(1,0), (0,1)$ 이 $R^2$의 기저 → $\dim(V) = 2$
- **예제 6-24**: $\mathbf{v}_1 = (0,1,1), \mathbf{v}_2 = (1,0,1), \mathbf{v}_3 = (1,1,2)$ 가 생성하는 $R^3$의 부분공간
  - $\mathbf{v}_3 = \mathbf{v}_1 + \mathbf{v}_2$ → 선형종속. $\{\mathbf{v}_1, \mathbf{v}_2\}$ 가 기저 → $\dim(V) = 2$
- **예제 6-25**: $R^4$의 4개 벡터 중 $\mathbf{v}_3 = -2\mathbf{v}_2$ → $\{\mathbf{v}_1, \mathbf{v}_2, \mathbf{v}_4\}$ 가 기저 → $\dim(V) = 3$

[보충] 차원을 구하는 실전 방법: 생성 벡터들을 열(또는 행)로 하는 행렬을 만들어 REF로 바꾸고 **피벗 개수(= rank)** 를 세면 된다. 즉 $\dim(\text{span}\{\mathbf{v}_1, \dots, \mathbf{v}_k\}) = \text{rank}[\mathbf{v}_1 \cdots \mathbf{v}_k]$ 다. 또 $\dim(R^n) = n$ 이고, $n$차원 공간에서 선형독립인 $n$개의 벡터는 **자동으로 기저**가 된다(생성 여부를 따로 확인할 필요가 없다).

## 핵심 정리

- 벡터공간의 핵심: **덧셈과 스칼라 곱에 대해 닫혀 있음** (+ 나머지 8개 공리)
- 부분공간 판별: ① 합에 닫힘, ② 스칼라 곱에 닫힘 (빠른 확인: $\mathbf{0}$ 포함 여부)
- **선형독립**: $\sum a_i\mathbf{v}_i = \mathbf{0}$ 의 해가 $a_i = 0$ 뿐
- **선형종속**: 어떤 벡터가 나머지의 선형결합으로 표현됨
- **생성(span)**: 모든 벡터를 선형결합으로 만들 수 있음
- **기저 = 선형독립 + 생성**
- **차원 = 기저 벡터의 개수**
- 표준기저: $\mathbf{e}_1, \dots, \mathbf{e}_n$ ($R^3$에서는 $\mathbf{i}, \mathbf{j}, \mathbf{k}$)
