# 선형대수학 퀴즈 출제 가이드

퀴즈를 새로 만들거나 해설을 쓸 때마다 이 파일을 먼저 읽고 따른다.

## 출제 규칙

- 문제는 한국어로 출제한다.
- 문제 유형: **전 문항 주관식** (계산, 서술, 증명 포함)
- 문항 수: 50문항
- 난이도: 어렵게
- 출제 범위: 1.1, 1.2, 2.1, 2.2, 2.3, 3.1, 3.2, 3.3, 3.4, 4.1, 4.2, 5.1, 5.2
- 챕터별로 묶지 않고 **챕터를 섞어 무작위 순서**로 출제한다. 문제에 절 번호를 표시하지 않는다.
- 강의 자료(`chapters/*.pdf`, `summaries/*.md`)를 기반으로 하되, 인터넷에 있는 문항을 가져와도 된다.
- 표기는 교재를 따른다: $\text{Det}(A)$, $|A|$, $\text{Adj}(A)$, $\text{tr}(A)$, $\text{rank}(A)$, 기본 행 연산 표기 $(-2) \times R_1 + R_2 \to R_2$
- 교재 정의가 일반 교재와 다른 부분(예: 회전 행렬의 방향, 가우스/가우스-조단 소거법의 구분)은 문제에서 조건을 명시해 모호하지 않게 한다.
- 파일은 `.md`로 만든다. VS Code 미리보기로 보면서 푼다 (LaTeX 수식 사용).
- 필요하면 그림을 만들어 넣는다. 그림은 `linear_algebra_quiz/figures/`에 SVG로 저장한다 (흰 배경, 파일 이름은 `q번호_내용.svg`).
- 문제 파일에는 **정답과 해설을 넣지 않는다.**
- 출제 중 모르거나 고민되는 부분은 사용자에게 물어보고 진행한다.

## 해설 규칙

- 사용자가 해설을 요청한 문항만 해설 파일에 작성한다.
- 해설 파일: `linear_algebra_quiz/quiz_N_explanation.md` (요청이 올 때마다 문항 번호 순서로 추가)
- 각 해설에는 정답과 풀이 과정을 함께 적는다.
