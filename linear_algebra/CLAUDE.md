# 선형대수학 강의 요약 규칙

## 요약 파일 작성 규칙

- 각 챕터별로 나누어 요약 파일을 만들 것 (챕터 하나당 파일 하나)
- 요약 내용은 한국어로 적을 것
- 강의 자료에 없는 보충 설명은 `[보충]` 표시로 구분할 것
- 요약 파일 이름은 영어로 할 것 (예: `ch01_linear_equations.md`)
- 표는 VS Code에서 마크다운 원문으로 볼 때 세로선(`|`)이 줄마다 맞도록 정렬한다. 각 칸을 공백으로 채워 열 너비를 맞추고, 한글 등 전각 문자는 2칸, 영문·숫자·기호는 1칸으로 계산한다. 한 줄이 너무 길어지지 않게 셀 내용은 짧게 쓰고, 긴 설명은 표 아래로 뺀다.

## 용어 정리 파일

- 챕터별 요약과 별도로, 용어만 모아 정리한 파일을 하나 더 만들 것
- 이 파일은 챕터별로 나누지 않고 하나의 파일로 통합할 것 (예: `glossary.md`)
