# GNU Vi (텍스트 에디터)

**과목**: CSE3209 System Programming
**출처**: GNU_study/pdf/GNU vi (1).pdf, https://www.gnu.org/software (일부 배경지식 보강)

## 1. Unix/Linux의 텍스트 에디터 계보

| 에디터 | 특징 |
|---|---|
| `ed`, `ex` | 초기 라인 기반(line-based) 에디터. `ex`는 `vi`의 라인 편집 명령(Last-Line Mode) 기반이 됨 |
| `vi` (`vim`) | 1976년 Bill Joy가 UC 버클리 대학원생 시절 BSD용으로 작성. 매우 가볍고 빠르며 거의 모든 Unix/Linux 시스템에 기본 탑재 |
| `emacs` | Richard Stallman이 작성. 매우 강력하지만 익히는 데 노력이 더 필요함 |

- **vim(Vi IMproved)**: 1991년 Bram Moolenaar가 vi를 확장해 만든 버전으로, vi보다 더 많은 기능(문법 강조, 멀티 undo, 플러그인 등)을 제공한다.
- 설치(Ubuntu): `sudo apt-get install vim`
- 버전 확인: `vi --version`

## 2. Vi 화면 구성 (Visual View)

- "Vi"는 **Visual Editor**의 약자 — 이전 라인 에디터(`ed`)와 달리 화면 전체를 보며 편집 가능.
- 화면 구성 요소:
  - **커서(Cursor)**: 현재 편집 위치
  - **파일 끝(End of file)** 표시
  - **화면 위치 비율**: 파일 내에서 현재 보이는 영역의 위치 (예: Top = 0%, All = 파일 전체가 한 화면에 보임)
  - **Vi 모드 표시줄**: 현재 모드(`-- INSERT --` 등)를 화면 하단에 표시
  - **커서 위치(줄, 칼럼)**

### 시작하기 (Getting Started)
1. `vi hello.c` — 새 파일 편집 시작 (셸에서 실행)
2. `i` — Insert Mode로 전환 후 타이핑 시작
3. `<Esc>` — 타이핑 종료, Command Mode로 복귀
4. `:wq` — 저장 후 종료

## 3. Vi의 3가지 모드 (3-state finite machine)

vi는 항상 아래 세 모드 중 **정확히 하나**의 상태에 있으며, 키 입력에 따라 모드가 전환된다.

```
                 a, i, o ...
   ┌────────────────────────────┐
   │                             ▼
Insert Mode  ◄──ESC──  Command Mode  ──:, /, ?──►  Last-Line Mode
                             ▲                            │
                             └────ESC, 실행(Enter)─────────┘
```

- vi를 처음 실행하면 항상 **Command Mode**로 시작한다.

### (1) Command Mode
- 기본 상태. Insert 모드도 Last-Line 모드도 아니면 Command Mode.
- **커서 이동**
  | 키 | 동작 |
  |---|---|
  | `w` | 한 단어 앞으로 이동 |
  | `b` | 한 단어 뒤로 이동 |
  | `^` | 줄의 첫 문자로 이동 |
  | `$` | 줄의 마지막 문자로 이동 |
  | `j` | 다음 줄로 이동 |
  | `k` | 이전 줄로 이동 |
  | `gg` | 파일의 첫 줄로 이동 |
  | `G` | 파일의 마지막 줄로 이동 |
  | `Ctrl-d` | 화면 반 페이지 아래로 스크롤 |
  | `Ctrl-u` | 화면 반 페이지 위로 스크롤 |

- **복사/붙여넣기**
  | 키 | 동작 |
  |---|---|
  | `yw` | 현재 단어를 버퍼로 복사(yank) |
  | `yy` | 현재 줄을 버퍼로 복사 |
  | `p` | 버퍼 내용을 현재 줄 아래에 붙여넣기 |

- **삭제**
  | 키 | 동작 |
  |---|---|
  | `x` | 현재 문자 삭제 |
  | `d` | 삭제 명령 접두사 (단독으로는 아무 것도 삭제하지 않음, 두 번째 키 필요) |
  | `dw` | 단어 끝까지 삭제 |
  | `dd` | 현재 줄 삭제 |

- **실행 취소**
  | 키 | 동작 |
  |---|---|
  | `u` | 편집 명령으로 인한 변경을 실행 취소(undo) |

- **숫자 접두사**: 대부분의 vi 명령 앞에 숫자를 붙이면 그 횟수만큼 반복 실행된다.
  - `5dd` → 5줄 삭제
  - `2yy` → 2줄 복사
  - `10j` → 10줄 아래로 이동

### (2) Insert Mode
- Command Mode에서 `i`, `a`, `o` 중 하나를 눌러 진입.
  | 키 | 동작 |
  |---|---|
  | `i` | 현재 문자 **앞**에 삽입 지점 위치 (insert to the left) |
  | `a` | 현재 문자 **뒤**에 삽입 지점 위치 (insert to the right) |
  | `o` | 현재 줄 **아래**에 새 줄을 열고 삽입 모드로 진입 |
- 하단에 `-- INSERT --` 문구가 표시되어 현재 모드를 알려준다.
- `<Esc>`를 누르기 전까지 입력하는 모든 문자는 텍스트로 그대로 삽입된다.

### (3) Last-Line Mode
- Command Mode에서만 진입 가능하며, `/`, `?`, `:` 세 키 중 하나로 시작한다. 화면 맨 아래 줄에 프롬프트가 나타난다.
- **검색**
  | 키 | 동작 |
  |---|---|
  | `/패턴` | 파일에서 앞으로(forward) 패턴 검색. `n`으로 다음 검색 결과로 이동 |
  | `?패턴` | 뒤로(backward) 패턴 검색 |
- **치환 예시**: `:1,$s/sss/ttt/` — 1번 줄부터 파일 끝(`$`)까지 `sss`를 `ttt`로 치환.
- **파일 관리 명령** (`:`로 시작)
  | 명령 | 동작 |
  |---|---|
  | `:#` | 지정한 줄 번호(`#`)로 이동 |
  | `:w [name]` | 편집 버퍼를 파일 `name`으로 저장 |
  | `:q` | 종료 (마지막 변경사항을 저장한 경우에만 가능) |
  | `:q!` | 변경사항을 저장하지 않고 강제 종료 |
  | `:wq` | 저장 후 종료 |
- **옵션 설정**
  | 명령 | 동작 |
  |---|---|
  | `:set number` / `:se nu` | 줄 번호 표시 |
  | `:set nonumber` / `:se nonu` | 줄 번호 숨김 |
  | `:set autoindent` / `:se ai` | 자동 들여쓰기 |
  | `:set tabstop=4` / `:se ts=4` | 탭 너비를 4칸으로 설정 |

## 요약 체크리스트
- vi는 **Command / Insert / Last-Line** 3가지 모드를 오가는 상태 기계로 동작한다는 점이 가장 중요한 개념.
- 편집 시작 흐름: `vi 파일명` → (Command Mode) `i`/`a`/`o`로 Insert 진입 → 편집 → `Esc`로 복귀 → `:wq`로 저장·종료.
- 저장/종료는 `:w`(저장), `:q`(종료), `:q!`(강제 종료), `:wq`(저장 후 종료)로 구분해서 기억.
- 삭제(`d`)·복사(`y`) 계열 명령은 뒤에 붙는 모션(`w`, `d`, `y` 반복 등)에 따라 범위가 결정되며, 숫자 접두사로 반복 횟수를 지정할 수 있다.
