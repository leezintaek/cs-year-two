## 1. Unix/Linux의 텍스트 에디터

| 에디터 | 만든 사람        | 특징                     |
| ------ | ---------------- | ------------------------ |
| ed, ex | -                | 줄 단위(line) 에디터     |
| vi     | Bill Joy (1976)  | 빠르고 모든 Unix에 존재  |
| vim    | Bram Moolenaar   | vi Improved (1991)       |
| emacs  | Richard Stallman | 강력하지만 배우기 어려움 |

- **vi** = **Vi**sual Editor. Bill Joy가 UC Berkeley 대학원생 시절 BSD용으로 작성
- **vim** = vi의 기능 확장판 (문법 강조, 다단계 undo, 분할 창 등)
- 💡 ex는 vi의 기반이 된 줄 단위 에디터입니다. vi의 `:` 명령(Last-Line mode)은 사실 ex 명령이라서, 이 모드를 "ex mode"라고도 부릅니다.

```bash
$ sudo apt-get install vim
$ vi --version
```

## 2. 화면 구성

- 맨 아래 줄(status line)에 표시되는 정보:
  - 현재 모드 (예: `-- INSERT --`)
  - 커서 위치 (줄, 열)
  - 파일 안에서의 화면 위치
    - `Top` : 파일 맨 위 (0%)
    - `Bot` : 파일 맨 아래
    - `All` : 파일 전체가 한 화면에 보임
- 파일 끝 이후의 빈 줄은 `~`로 표시

---

## 3. 시작하기

1. 셸에서 `vi hello.c` 입력
2. `i`를 눌러 Insert mode로 전환 후 입력
3. 입력이 끝나면 `<Esc>`
4. `:wq` 입력 → 저장 후 종료

---

## 4. vi의 3가지 모드 (유한 상태 기계)

```
              a, i, o ...                 :, /, ? ...
 Insert  <───────────────  Command  ───────────────>  Last-Line
  Mode   ───────────────>    Mode   <───────────────    Mode
                ESC                   ESC / 명령 실행
```

- 시작하면 항상 **Command Mode**
- 키를 누를 때마다 현재 모드에 머물거나 다른 모드로 전환
- 어느 순간이든 **정확히 하나의 모드**에만 있음
- Insert ↔ Last-Line 사이는 직접 이동 불가, **반드시 Command Mode를 거침**

💡 Vim에는 이외에도 **Visual mode**(`v` 문자 단위, `V` 줄 단위, `Ctrl-v` 블록 단위로 영역 선택)와 **Replace mode**(`R`, 덮어쓰기)가 있습니다. 어떤 모드인지 헷갈리면 `<Esc>`를 몇 번 눌러 Command Mode로 돌아오면 됩니다.

## 5. Insert Mode

| 키  | 동작                               |
| --- | ---------------------------------- |
| `i` | 현재 글자 **앞**에 삽입            |
| `a` | 현재 글자 **뒤**에 삽입            |
| `o` | 현재 줄 **아래**에 새 줄 열고 삽입 |

- 화면 아래에 `-- INSERT --` 표시
- `<Esc>`를 누를 때까지 입력한 모든 것이 텍스트로 들어감

💡 **추가 진입 키**

| 키   | 동작                         |
| ---- | ---------------------------- |
| `I`  | 줄의 맨 앞(공백 제외)에 삽입 |
| `A`  | 줄의 맨 끝에 삽입            |
| `O`  | 현재 줄 **위**에 새 줄 삽입  |
| `s`  | 현재 글자 지우고 삽입        |
| `cw` | 단어 끝까지 지우고 삽입      |
| `cc` | 줄 전체 지우고 삽입          |

## 6. Last-Line Mode

Command Mode에서 `:`, `/`, `?` 중 하나를 누르면 진입하며, 화면 맨 아래 줄에 프롬프트가 생깁니다. 명령 입력 후 `Enter`로 실행합니다.

### 검색

| 명령       | 동작                    |
| ---------- | ----------------------- |
| `/pattern` | 아래 방향으로 검색      |
| `?pattern` | 위 방향으로 검색        |
| `n`        | 같은 방향으로 다음 결과 |
| `N` 💡     | 반대 방향으로 다음 결과 |

### 치환
```
:1,$s/sss/ttt/      1번 줄부터 마지막 줄($)까지, 각 줄의 첫 번째 sss를 ttt로
```

💡 **치환 명령 보충**

| 명령            | 의미                          |
| --------------- | ----------------------------- |
| `:s/a/b/`       | 현재 줄의 첫 a만              |
| `:s/a/b/g`      | 현재 줄의 모든 a              |
| `:1,$s/a/b/g`   | 파일 전체의 모든 a            |
| `:%s/a/b/g`     | 위와 같음 (`%` = `1,$`)       |
| `:%s/a/b/gc`    | 하나씩 확인(confirm)하며 치환 |
| `:10,20s/a/b/g` | 10~20번 줄만                  |

슬라이드의 `:1,$s/sss/ttt/`는 끝에 `g`가 없어서 **각 줄의 첫 번째**만 바뀝니다. 한 줄에 여러 개가 있으면 `g`를 붙여야 합니다.

### 파일 관리

| 명령      | 동작                               |
| --------- | ---------------------------------- |
| `:#`      | #번 줄로 이동 (예: `:15`)          |
| `:w`      | 저장                               |
| `:w name` | name이라는 파일로 저장             |
| `:q`      | 종료 (마지막 변경을 저장한 경우만) |
| `:q!`     | 저장하지 않고 강제 종료            |
| `:wq`     | 저장 후 종료                       |

💡 `:x` 또는 Command Mode의 `ZZ`도 "저장 후 종료"입니다(변경이 없으면 파일을 다시 쓰지 않음). `:e file`은 다른 파일 열기, `:!cmd`는 vi 안에서 셸 명령 실행(예: `:!gcc -Wall %` — `%`는 현재 파일 이름)입니다.

### 옵션 설정

| 명령                          | 의미           |
| ----------------------------- | -------------- |
| `:set number` / `:se nu`      | 줄 번호 표시   |
| `:set nonumber` / `:se nonu`  | 줄 번호 숨기기 |
| `:set autoindent` / `:se ai`  | 자동 들여쓰기  |
| `:set tabstop=4` / `:se ts=4` | 탭 너비 4칸    |

💡 매번 입력하지 않으려면 홈 디렉터리의 `~/.vimrc` 파일에 적어 둡니다 (`:` 없이).
```vim
set number
set autoindent
set tabstop=4
set shiftwidth=4
syntax on
```

## 7. Command Mode

`-- INSERT --`도 안 보이고 아래 줄에 `:`, `/`, `?` 프롬프트도 없으면 Command Mode입니다.

### 커서 이동

| 키   | 동작               |
| ---- | ------------------ |
| `w`  | 다음 단어로        |
| `b`  | 이전 단어로        |
| `^`  | 줄의 첫 글자로     |
| `$`  | 줄의 마지막 글자로 |
| `j`  | 다음 줄 (아래)     |
| `k`  | 이전 줄 (위)       |
| `gg` | 파일 첫 줄로       |
| `G`  | 파일 마지막 줄로   |

💡 `h`(왼쪽), `l`(오른쪽)도 기본 이동 키입니다. `h j k l` = 좌 하 상 우. `0`은 줄의 0번째 칸(공백 포함 맨 앞), `숫자G`는 해당 줄로 이동(예: `15G` = `:15`), `%`는 짝이 되는 괄호로 이동합니다(C 코딩에 유용).

### 화면 이동

| 키       | 동작                |
| -------- | ------------------- |
| `Ctrl-d` | 화면 반 페이지 아래 |
| `Ctrl-u` | 화면 반 페이지 위   |

💡 `Ctrl-f` / `Ctrl-b` : 한 페이지 전체 아래/위

### 복사와 붙여넣기 (yank & put)

| 키   | 동작                           |
| ---- | ------------------------------ |
| `yw` | 현재 단어를 버퍼에 복사        |
| `yy` | 현재 줄을 버퍼에 복사          |
| `p`  | 버퍼 내용을 아래 줄에 붙여넣기 |

💡 `P`(대문자)는 **위/앞**에 붙여넣습니다. 복사(yank)한 것은 줄 단위면 줄 아래로, 문자 단위면 커서 뒤로 붙습니다.

### 삭제

| 키   | 동작             |
| ---- | ---------------- |
| `x`  | 현재 글자 삭제   |
| `dw` | 단어 끝까지 삭제 |
| `dd` | 현재 줄 삭제     |

- `d`만 누르면 아무 일도 안 일어남 → 두 번째 키(이동 명령)가 필요
- 💡 삭제된 내용은 버퍼에 저장되므로 `dd` 후 `p`를 누르면 **잘라내기-붙여넣기**가 됩니다.
- 💡 `D` 또는 `d$` : 커서부터 줄 끝까지 삭제, `dG` : 현재 줄부터 파일 끝까지 삭제

### 되돌리기

| 키       | 동작                     |
| -------- | ------------------------ |
| `u`      | 실행 취소 (undo)         |
| `Ctrl-r` | 💡 다시 실행 (redo, vim) |
| `.`      | 💡 마지막 편집 명령 반복 |

### 숫자 접두사 (반복 횟수)

명령 앞에 숫자를 붙이면 그 횟수만큼 실행합니다.

| 명령  | 동작             |
| ----- | ---------------- |
| `5dd` | 5줄 삭제         |
| `2yy` | 2줄 복사         |
| `10j` | 10줄 아래로 이동 |

💡 **vi 명령의 문법: `[횟수] 연산자 이동`**
- 연산자: `d`(삭제), `y`(복사), `c`(변경)
- 이동: `w`, `b`, `$`, `G`, `j` ...
- 예: `d3w` = 3단어 삭제, `y$` = 줄 끝까지 복사, `cG` = 끝까지 지우고 입력
이 규칙만 알면 명령을 외우지 않고 조합해서 쓸 수 있습니다.

## 8. 자주 쓰는 명령 요약

| 상황              | 명령                     |
| ----------------- | ------------------------ |
| 입력 시작         | `i`, `a`, `o`            |
| 입력 끝           | `<Esc>`                  |
| 저장/종료         | `:w`, `:q`, `:wq`, `:q!` |
| 줄 번호 표시      | `:set nu`                |
| N번 줄로          | `:N` 또는 `NG`           |
| 검색              | `/word`, `n`             |
| 전체 치환         | `:%s/old/new/g`          |
| 줄 삭제/복사/붙임 | `dd`, `yy`, `p`          |
| 실행 취소         | `u`                      |
