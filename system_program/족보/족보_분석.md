## 2. 모의문제(quiz_set1~5)와 비교

### 겹치는 유형 (모의문제로 연습 가능)

- 메모리 표 mov/movs/lea: Set1 14, Set2 16, Set3 14·16
- jmp → C: Set2 15, Set3 15 (족보2 1번 `funny`와 구조가 거의 같음), Set4 15
- INT_MIN 연산과 `~x + x`: Set2 T/F 2, Set4 B7, Set5 17
- signed/unsigned 비교: Set3 B7, Set5 14
- 플래그, jl/jb: Set1 16, Set4 16·B11
- 컴파일 단계와 심볼 테이블: Set1 B6, Set3 T/F 1, Set4 T/F 1

### 모의문제에 없는 유형 (따로 볼 것)

**1. 8비트 미니 float** (족보 3개에 모두 출제)
- bias = 2^(k−1) − 1 (k = 지수 비트 수)
- 예: Sign 1 / Exponent 3 / Mantissa 4
  - bias = 2² − 1 = **3**
  - `1 010 1000` → S = 1, e = 2 → E = −1, M = 1.1(2) → −1.5 × 2⁻¹ = **−0.75**
  - 최대 정규화 값: e = `110`(6) → E = 3, f = `1111` → 1.1111(2) × 2³ = 1111.1(2) = **15.5**
- 족보2 6번은 Sign 1 / Exponent 5 / Mantissa 2 형식 → bias = 2⁴ − 1 = **15**

**2. float → int 범위 초과**
- `float f = 1e10; (int) f` → int 범위를 넘으므로 x86-64에서는 **`0x80000000`**(TMin)
- double → int도 같은 이유로 `80000000`
- C 표준은 아니지만 x86-64가 이렇게 동작한다고 강의에서 다뤘다.
- 참고: arm64(Mac)에서 돌리면 `7fffffff`가 나온다. 시험은 x86-64 기준.

**3. `1e20 - 10` 흡수 (무한 루프)**
```c
float f1 = 1e20, f2 = 10;
while (f1 > 1e19) f1 -= f2;
```
- 1e20 근처에서 float가 표현할 수 있는 간격은 10보다 훨씬 크다(가수 23비트).
- 그래서 `f1 - 10`을 반올림하면 **다시 1e20**이 되어 f1이 줄지 않는다 → 무한 루프.
- 실행해서 `f1 - f2 == f1`이 참인 것을 확인했다.

**4. unsigned `length - 1` 버그**
```c
float foo(float a[], unsigned length) {
    for (i = 0; i <= length - 1; i++) result += a[i];
}
```
- length = 0이면 `length - 1` = UMAX가 된다.
- `i`도 unsigned로 바뀌어 비교되므로 `i <= UMAX`가 항상 참이다 → 배열 범위를 넘어 segfault.
- 해결: `int length`로 바꾸거나 조건을 `i < length`로 바꾼다.

**5. static / extern, gdb·gcc 명령어** (GNU_study 범위)
- 전역 `static`: 이 파일 안에서만 보인다 (다른 파일에서 접근 불가).
- 지역 `static`: 함수 호출이 끝나도 값이 유지된다.
- `extern`: 다른 파일에 정의된 전역 변수를 쓰겠다고 선언 (분할 컴파일 시 링커가 연결).
- gdb에서 디스어셈블: `disas 함수명`
- 디버깅 레벨 3 + 실행 파일 이름 지정: `gcc -m64 -o myprog -g3 foo.c`

## 3. ⚠️ 족보에 적힌 답 중 틀린 것

족보 PDF에 적힌 답은 학생이 쓴 답이라 틀린 것이 섞여 있다.

**족보1**
- **1-(2)**: "A는 다른 파일에서도 사용 가능" → 틀림. 전역 `static`(A)은 **이 파일 안에서만** 보인다. 지역 `static`(B)은 호출이 끝나도 값이 유지된다.
- **2-(1)**: `char c = 100 + 30;` 출력 130 → 틀림. 정답 **−126** (char 오버플로우: 130 − 256)
- **3번 `arith`**
  ```
  lea  (%rsi,%rsi,4), %rax     # rax = 5y
  sub  %rax, %rdx              # rdx = z - 5y
  mov  %rdx, (%rdi,%rsi,8)     # x[y] = rdx
  ```
  - (1) 정답: `t1 = 5*y;` `t2 = z - t1;` `x[y] = t2;` (`-t1`, `x[z]`는 틀림)
  - (2) gdb 명령: **`disas arith`** (`objdump -d`는 gdb 명령이 아니다)
- **5번** (`%rax = 0x40`, `%rsi = 2`)
  - (a) `leaq (%rsi,%rsi,4), %rbx` → `0xA` (맞음)
  - (b) `movw 10(%rax), %cx` → 주소 0x4A, 0x4B = `08 15` → **`0x1508`** (`0x0803`은 틀림)
  - (c) `movsbl -2(%rax,%rsi,2), %edi` → 주소 0x40 + 4 − 2 = 0x42 = `B3` → sign-extend → **`0xFFFFFFB3`** (`0x17`은 틀림)
- **6번**: 출력 "2 3 4 5" → 틀림. 정답 **"2 3"** (실행해서 확인함)
  - `x = INT_MIN`, `y = 0x80000000`(unsigned), `z = ~x = INT_MAX`
  - `-1 < 0U`: −1이 UMAX가 됨 → 거짓
  - `-x < 0`: −INT_MIN = INT_MIN → 참 → **2**
  - `x - 1 < y`: x − 1 = INT_MAX, unsigned 비교 `0x7FFFFFFF < 0x80000000` → 참 → **3**
  - `y <= z`: unsigned 비교 `0x80000000 <= 0x7FFFFFFF` → 거짓
  - `x + z <= 0U`: x + z = −1 → UMAX ≤ 0 → 거짓
- **7번**: "아니오"는 맞지만 이유가 틀림. 0이 되는 게 아니라 `f1 - 10`이 반올림으로 **다시 f1이 되어** 무한 루프. (2절 3번 참고)

**족보2**
- **1-(1)**: 빈칸은 `if`가 아니라 **`while (y > 10)`**. 맨 앞 `jmp`가 test(cmp)로 먼저 가는 jump to middle 구조다.
  ```c
  long funny(long x, long y) {
      while (y > 10) {
          x++;
          y--;
      }
      return x + y;
  }
  ```
- **1-(2)** (답란 비어 있음): `%rsi = 0xb`(11)에서 `cmp $0xa, %rsi` → 11 − 10 = 1 → **ZF = 0, SF = 0, OF = 0**
- **8번** (`%rax = 4`, `%rsi = 2`)
  - (1) `movl 2(%rax), %ebx` → 주소 6 ~ 9 = `10 E7 F7 84` → **`0x84F7E710`** (`0x10`은 틀림)
  - (2) `leal (%rax,%rax,2), %ecx` → lea는 메모리를 읽지 않음 → 4 + 4×2 = **`0x0000000C`** (`0xA5`는 틀림)
  - (3) `movsbw 4(%rax), %dx` → 주소 8 = `F7` → `0xFFF7` (맞음)

### 맞는 답 (믿어도 됨)
- 족보1 1-(1) 출력 순서, 2-(2) `2*INT_MIN` = 0, 4번 컴파일 4단계, 8번 미니 float (3 / −0.75 / 15.5)
- 족보2 2번 `80000000` / `80000000`, 3번 (`-o myprog -g3`, unsigned 원인, int로 수정), 8-(3) `0xFFF7`

### 답이 비어 있던 문항
- **족보2 5번** (`x = INT_MIN`, 실행해서 확인함)
  - `x - 1` → **2147483647**
  - `-x` → **−2147483648**
  - `(unsigned) x` → **2147483648**
  - `~x + x` → **−1**
- **족보2 7번** (실행해서 확인함)
  - `short y = (short) 0x12345678` → 하위 16비트 → `printf("%x", y)` → **5678**
  - `y < -1U` → y가 unsigned로 바뀌어 `0x5678 < 0xFFFFFFFF` → 참 → **1**
