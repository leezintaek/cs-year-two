# Week 3: Floating Point (부동소수점)

교재: Computer Systems 3rd Edition by Bryant, Chap 2.

## 1. 실수 표현의 필요성

- 프로그래밍 언어는 정수뿐 아니라 실수(real number)도 지원해야 하며, 이를 floating-point number(부동소수점 수)라고 부른다.
- 예: π = 3.14159265…, e = 2.71828…, 나노초(1.0×10⁻⁹), 하루의 나노초 수(8.64×10¹³) 등.
- 매우 크거나 작은 수를 표현하기 위해 과학적 표기법(scientific notation)을 사용한다.
  - 형태: ± d.f₁f₂f₃f₄… × 10^(±e₁e₂e₃), 여기서 d는 [1, 10) 범위.

## 2. 고정소수점(Fixed Point) 표현

- 이진수의 binary point(소수점) 오른쪽 비트들이 2의 음의 거듭제곱(1/2, 1/4, 1/8, …)을 나타낸다.
- 값 = Σ bₖ × 2ᵏ (k = -j부터 i까지)
- 예: 3.4375(10) = 11.0111(2)
  - 소수 부분 변환법: 0.4375 × 2를 반복하며 정수부를 취함 (0.4375→0.875→0.75→0.5→0 순으로 0,1,1,1 추출)

### 고정소수점의 한계
1. **한계 1 — 표현 범위 제한**: 아주 크거나 아주 작은 값을 표현하기 어렵다.
2. **한계 2 — 정확한 표현 불가**: x/2ᵏ 형태의 수만 정확히 표현 가능. 1/3, 1/5, 1/10 같은 유리수는 순환하는 비트 패턴을 가진다.
   - 1/3 = 0.0101010101[01]…
   - 1/5 = 0.001100110011[0011]…
   - 1/10 = 0.0001100110011[0011]…

## 3. IEEE 754 부동소수점 표준

- 1985년에 제정된 부동소수점 연산의 표준(IEEE 754).
- 수치 형태(Numerical Form): **값 = (-1)^S × M × 2^E**
  - S(sign): 부호 비트 (양수/음수 결정)
  - M(mantissa/가수): 보통 [1.0, 2.0) 범위의 값
  - E(exponent/지수): 2의 거듭제곱 가중치
- 비트 구성: `<S, E, M>` ↔ `<s:1, e:k, f:n>`
  - **단정도(single precision)**: k=8 (지수 8비트), n=23 (가수 23비트) → 총 32비트
  - **배정도(double precision)**: k=11 (지수 11비트), n=52 (가수 52비트) → 총 64비트

### 예시
- 1(10) = 1.0(2) × 2⁰ → S=0, M=1.0, E=0
- 2.75(10) = 10.11(2) = 1.011(2) × 2¹ → S=0, M=1.011, E=1

## 4. 비트 필드 변환 방법

### Sign (S)
- s = 0 (양수), s = 1 (음수) — 그대로 사용.

### Mantissa (M) → fraction (f)
- M = 1(hidden bit, 암묵적 선행 비트) + f
- 가장 왼쪽의 항상 1인 비트를 제거하고 나머지를 f로 저장 (single: 23비트, double: 52비트)

### Exponent (E) → biased exponent (e)
- e = E + bias (bias를 더해서 부호 없는(unsigned) 표현으로 변환)
- **bias = 2^(k-1) - 1**
  - Single precision: bias = 127 (e 범위: 1~254, E 범위: -126~127)
  - Double precision: bias = 1023 (e 범위: 1~2046, E 범위: -1022~1023)
- e = 0과 e = 모두 1(255 또는 2047)은 특수 목적으로 예약됨.

### 예시: float f = 15213.0f
- 15213(10) = 11 1011 0110 1101(2) = 1.1101 1011 0110 1(2) × 2¹³
- S=0, M=1.1101 1011 0110 1, E=13
- f = 0.1101 1011 0110 1000…(23비트), e = 13+127 = 140 = 1000 1100(2)
- 결과: `0 10001100 11011011011010000000000`

### 부동소수점 값 해석(Interpretation) — 반대 방향 변환
- 비트 패턴 → S, e, f를 읽고 → E = e - bias, M = 1.f 계산 → 값 = (-1)^S × M × 2^E
- 예: `0 10000000 10100...0` → S=0, e=128→E=1, M=1.101 → 값 = 1.101×2¹ = 11.01(2) = 3.25

## 5. Normalized / Denormalized / Special Values

지수 필드(e) 값에 따라 세 가지 범주로 나뉜다.

### (1) 정규화(Normalized) 형태
- 조건: e ≠ 0 이고 e ≠ 모두 1 (가장 일반적인 경우)
- M = 1 + f (hidden bit 존재), E = e - bias

### (2) 비정규화(Denormalized) 형태
- 조건: e = 000…0 (지수 필드가 모두 0)
- **0을 표현하기 위해 필요** — 정규화 형태는 M ≥ 1이라 0을 표현할 수 없음.
- M = f (hidden bit 없음, 1 대신 0으로 시작), E = 1 - bias (0 - bias 대신)
- 즉 값 = f × 2^(1-bias) (정규화 시 1.f × 2^(0-bias)가 아님에 주의)
- "Zero"는 e=0, f=0일 때 표현됨.
- 최소 정규화 값(1×2⁻¹²⁶)과 비정규화 최댓값(0.111…1×2⁻¹²⁶) 사이에 **부드러운 전환(smooth transition)**을 제공.
- 부호 비트에 따라 +0과 -0이 모두 존재 가능.

### (3) 특수값(Special Values)
- 조건: e = 111…1 (지수 필드가 모두 1)
  - Single precision: e = 255, Double precision: e = 2047
- **무한대(Infinity)**: f = 000…0 일 때. 오버플로우(예: 1.0/0.0)의 결과로 발생. 부호에 따라 +∞, -∞.
- **NaN (Not a Number)**: f ≠ 000…0 일 때. 실수나 무한대로 표현할 수 없는 연산 결과.
  - 예: sqrt(-1), ∞-∞, NaN에 대한 연산, 초기화되지 않은 데이터

## 6. 표현 범위 (Single / Double Precision)

| 구분 | Single Precision | Double Precision |
|---|---|---|
| 최대 정규화 값 | ≈ 3.4028×10³⁸ | ≈ 1.79769×10³⁰⁸ |
| 최소 정규화 값 | ≈ 1.17549×10⁻³⁸ | ≈ 2.22507×10⁻³⁰⁸ |
| 최대 지수 E | 127 | 1023 |
| 최소 지수 E | -126 | -1022 |

- **오버플로우(Overflow)**: 지수가 지수 필드에 담기에 너무 큰 경우.
- **언더플로우(Underflow)**: 지수가 지수 필드에 담기에 너무 작은 경우.

## 7. 반올림(Rounding)

- x +f y = Round(x + y), x ×f y = Round(x × y) — 먼저 정확한 결과를 계산한 뒤 원하는 정밀도에 맞게 반올림.
- **기본 반올림 모드: Round-to-Even(짝수로 반올림)**
  - 다른 방식들은 통계적으로 편향됨(양수 집합의 합이 지속적으로 과대/과소 추정될 수 있음).
  - 정확히 절반(halfway)일 때, 최하위 자리가 짝수가 되도록 반올림.
  - 예(10진수): 7.8949999→7.89, 7.8950001→7.90, 7.8950000(halfway)→7.90(짝수), 7.8850000(halfway)→7.88(짝수)
- **이진수에서의 round-to-even**: X = a.bcdefg…에서 반올림 위치가 정확히 절반(a.bcd1000)일 때, 결과의 최하위 비트가 0(짝수)이 되도록 반올림.
  - 예: 10.11100 → 11.00 (반올림), 10.10100 → 10.10 (버림)

## 8. 부동소수점 덧셈(Floating Point Addition)

절차:
1. 두 수의 지수가 다르면 바로 더할 수 없음 → **작은 지수를 가진 수의 가수를 오른쪽으로 시프트**하여 지수를 맞춤.
2. 가수(significand)를 더한다.
3. 결과가 정규화 형태가 아니면 **정규화(normalize)** — 필요시 시프트하며 지수를 조정(carry 발생 시 오른쪽으로 1비트 시프트 후 지수 증가).
4. 정해진 비트 수에 맞게 **반올림(round)** — 반올림으로 인해 carry가 발생하면 재정규화.
5. 지수가 너무 크거나 작아지면 오버플로우/언더플로우 검출.

예: (1.111)₂×2⁻¹ + (1.011)₂×2⁻³ = (10.00111)₂×2⁻¹ → 정규화 → (1.000111)₂×2⁰ → 반올림 → (1.001)₂×2⁰

## 9. 부동소수점 곱셈(Floating Point Multiplication)

절차:
1. **지수는 서로 더한다** (덧셈과 다른 점).
2. **가수는 서로 곱한다**.
3. 부호는 XOR: 두 피연산자의 부호가 다르면 결과는 음수.
4. 결과를 정규화(최대 1비트만 시프트하면 됨).
5. 반올림하여 정해진 비트 수에 맞춘다.

예: 1.010₂×2⁻¹ × (-1.110₂×2⁻²) → 지수 = -3, 가수 곱 = 10.001100₂ → 정규화하여 1.0001100₂×2⁻² → 반올림 → 결과 ≈ -1.001₂×2⁻²

## 10. C 언어에서의 부동소수점

### 형변환(Casting)
- **int → float**: 가수(23비트)가 부족하면 반올림될 수 있음 (정확하지 않을 수 있음).
- **int → double**: 52비트 가수로 대부분 정확한 변환 가능.
- **double/float → int**:
  - 범위를 벗어나면(오버플로우) 결과가 정의되지 않으나, 일반적으로 Tmin(예: -2147483648)으로 설정됨. (C 표준은 아님)
  - 소수 부분은 버림(truncate, 0 방향으로 반올림). 1.999→1, -1.999→-1

### 주의할 함정
- **0.1, 0.2 같은 "간단한" 소수도 이진수로 정확히 표현되지 않는다** (순환소수이기 때문).
- **비교(==) 연산은 반올림 오차로 인해 예상치 못한 결과를 반환할 수 있음** → 부동소수점 등호 비교는 피해야 함.
- **부동소수점 연산은 결합법칙(associativity)이 성립하지 않는다.**
  - 예: (3.14f + 1e20) - 1e20 = 0.0 이지만, 3.14f + (1e20 - 1e20) = 3.14 — 계산 순서에 따라 다른 결과.

## 11. 요약 (Summary)

- IEEE 부동소수점 표준: Single Precision(SP), Double Precision(DP)
- 반올림(Rounding), 덧셈(Addition), 곱셈(Multiplication)의 동작 원리
- C 언어에서의 부동소수점 처리
- 부동소수점 연산은 실수(real number) 연산과 동일하지 않음
  - 결합법칙(associativity), 분배법칙(distributivity)이 성립하지 않음
  - 컴파일러 및 수치 계산을 다루는 프로그래머에게 어려움을 야기함
