## 1. 플립플롭 기초 [5장 p.3–4]
- 일반적인 디지털 시스템은 **기억소자**와 **조합 논리회로**로 이루어진다(그림 5-1).
- **플립플롭(FF)**: 논리 게이트를 조합해서 만든 기억소자.
- 출력 Q는 정상 출력, Q̄는 반전 출력이다. **Q̄는 항상 Q의 반전**이다.
- FF가 HIGH(1) 상태라는 말은 Q=1이라는 뜻이고, LOW(0) 상태라는 말은 Q=0이라는 뜻이다.

| 상태 | Q | Q̄ | 이름 |
|---|---|---|---|
| 세트(Set) | 1 | 0 | HIGH 또는 1 상태 |
| 클리어(Clear) = 리셋(Reset) | 0 | 1 | LOW 또는 0 상태 |

- 대부분의 FF는 SET 입력과 CLEAR(RESET) 입력을 가진다.
- FF는 **래치(latch)**, **쌍안정 멀티바이브레이터(bistable multivibrator)**라고도 부른다.

## 2. 5.1 NAND 게이트 래치 [5장 p.5–12]

### 구조
- NAND 게이트 2개를 교차 결합(cross-coupled)한 구조다. 각 게이트의 출력이 다른 게이트의 입력으로 피드백된다.
- **SET = CLEAR = 1일 때 가능한 출력 상태는 Q=0, Q=1 두 가지다.** 둘 중 어느 상태인지는 이전 상태가 정한다. 이것이 기억 작용이다. [p.5]

### 세트 동작 [p.6]
- CLEAR = HIGH를 유지하면서 SET에 순간적으로 LOW 펄스를 넣는 경우.
  - 이전에 Q=0이었으면 Q가 HIGH(1)로 바뀐다. SET이 HIGH로 돌아가도 Q=1이 유지된다.
  - 이전에 Q=1이었으면 상태가 변하지 않고 계속 Q=1이다.
- 결론: CLEAR가 HIGH인 동안 SET에 LOW 펄스를 넣으면 NAND 래치는 **항상 Q=1**이 된다. 이 동작을 "세트되었다"고 한다.

### 리셋(클리어) 동작 [p.7]
- SET = HIGH를 유지하면서 CLEAR에 LOW 펄스를 넣는 경우.
  - 이전에 Q=0이었으면 영향이 없다. Q=0이 유지된다.
  - 이전에 Q=1이었으면 Q가 LOW가 된다. CLEAR가 HIGH로 돌아가도 Q=0이 유지된다.
- 결론: **항상 Q=0**이 된다. 이 동작을 래치의 클리어 또는 리셋이라고 한다.

### 동시에 세트와 클리어 [p.8]
- SET과 CLEAR에 동시에 LOW를 넣으면 **Q = Q̄ = 1**이 된다. 이는 Q̄가 Q의 반전이라는 규칙에 어긋나는 상태다.
- 이후 두 입력이 HIGH로 돌아갈 때 **어느 쪽이 먼저 HIGH가 되느냐**에 따라 결과가 정해진다. 두 입력이 동시에 HIGH가 되면 출력을 **결정할 수 없다**.
- 따라서 SET = CLEAR = 0 조건은 NAND 래치에서 **사용하지 않는다**.

### NAND 래치 요약표 [p.9, p.12]

| SET | CLEAR | 출력 |
|---|---|---|
| 1 | 1 | 변화 없음 (이전 상태 유지) |
| 0 | 1 | Q = 1 (세트) |
| 1 | 0 | Q = 0 (클리어/리셋) |
| 0 | 0 | 사용 안 됨 (Q = Q̄ = 1이 됨) |

### 등가 표현과 용어 [p.10]
- NAND 래치는 **동적(active) LOW** 입력이다. SET이 LOW일 때 Q=1, CLEAR가 LOW일 때 Q=0이 된다.
- 그래서 입력을 S̄(SET̄), R̄(CLEAR̄/RESET̄)로 쓰고, 기호에서는 입력에 **작은 원(버블)**을 붙인다.
- 등가 회로: NAND 게이트는 "입력에 버블이 붙은 OR 게이트"로 그릴 수 있다(그림 5-6).
- 용어 정리
  - FF나 래치를 클리어시키는 동작을 **리셋**이라고도 한다.
  - CLEAR 입력을 RESET 입력이라고도 한다.
  - SET-RESET 래치를 SET-CLEAR 래치라고도 한다.

### 예제 5-1: NAND 래치 파형 (초기 Q=0) [p.11]

| 시점 | SET̄ | RESET̄ | 동작 | Q |
|---|---|---|---|---|
| t1 | 1 | 0 펄스 | 리셋 (이미 Q=0) | 0 유지 |
| t2 | 0 펄스 | 1 | 세트 | 0 → 1 |
| t3 | 1로 복귀 | 1 | 변화 없음 | 1 |
| t4 | 0 펄스 | 1 | 세트 (이미 Q=1) | 1 유지 |
| t5 | 1 | 0 펄스 | 리셋 | 1 → 0 |
| t6 | 1 | 1로 복귀 | 변화 없음 | 0 |

### 예제 5-2: 접촉 바운스와 디바운스 회로 [p.12]
- **바운스(bounce)**: 기계식 스위치가 접점에 닿을 때 여러 번 튀면서 출력이 0과 5V 사이를 몇 번 오가는 현상이다. 그 뒤에 안정된다.
- **디바운스(debounce) 회로**: 바운스가 출력에 영향을 주지 않도록 막는 회로다. NAND 래치(S̄, R̄)를 쓰고, 각 입력에 +5V 풀업 저항을 단다.
  - 스위치가 접점 1에 있으면 S̄=1, R̄=0이므로 Q=0이다.
  - 스위치가 접점 2로 옮겨 가면 S̄=0이 되어 Q=1로 세트된다.
  - 스위치가 접점 2에서 튀면서 순간적으로 떨어지면 S̄ = R̄ = 1이 된다. 이는 "변화 없음" 상태이므로 **출력이 흔들리지 않는다**.
  - 결과적으로 V_OUT은 스위치가 접점 2로 가는 순간 깨끗하게 1로 올라가고, 접점 1로 돌아오는 순간 0으로 내려간다.

## 3. 5.2 NOR 게이트 래치 [5장 p.13–14]
- NOR 게이트 2개를 교차 결합한 구조다. Q와 Q̄의 위치가 바뀐 것을 빼면 NAND 래치와 비슷하다. 그림에서는 SET 쪽 게이트의 출력이 Q̄이고, RESET 쪽 게이트의 출력이 Q다.
- 입력은 **동적 HIGH**이다. SET과 CLEAR가 동적 LOW가 아니라 동적 HIGH라는 점만 다르고, 나머지 동작은 NAND 래치와 똑같다.

| SET | CLEAR(RESET) | 출력 |
|---|---|---|
| 0 | 0 | 변화 없음 (이전 상태 유지) |
| 1 | 0 | Q = 1. SET이 0으로 돌아가도 HIGH 유지 |
| 0 | 1 | Q = 0. CLEAR가 0으로 돌아가도 LOW 유지 |
| 1 | 1 | 사용 안 됨 (**Q = Q̄ = 0**이 됨) |

- 기호에는 입력 버블이 없다. 입력은 S, R이다.

### 예제 5-3: NOR 래치 파형 (초기 Q=0) [p.14]

| 시점 | 입력 | Q |
|---|---|---|
| t1 | SET 1 | 0 → 1 |
| t2 | SET 0으로 복귀 | 1 유지 |
| t3 | RESET 1 | 1 → 0 |
| t4 | RESET 0으로 복귀 | 0 유지 |
| t5 | RESET 1 (이미 0) | 0 유지 |
| t6 | SET 1 | 0 → 1 |

> NAND와 NOR 비교: "사용 안 됨" 입력은 NAND가 00, NOR가 11이다. 그때 출력은 NAND가 Q=Q̄=**1**, NOR가 Q=Q̄=**0**이다. "변화 없음" 입력은 NAND가 11, NOR가 00이다.

## 4. 5.4 디지털 펄스 [5장 p.15–16]
- **펄스 신호**: 한 신호가 평소의 비활성 상태에서 반대 상태로 바뀌어 회로에 영향을 주고, 다시 비활성 상태로 돌아간 뒤에도 그 영향이 시스템에 남는 경우를 말한다.
- **양(positive) 펄스**: 평소 LOW였다가 HIGH로 변할 때 원하는 기능을 수행한다.
- **음(negative) 펄스**: 평소 HIGH였다가 LOW로 변할 때 원하는 기능을 수행한다.
- **천이 시간(transition time)**: 한 레벨에서 다른 레벨로 바뀌는 데 걸리는 시간.
- **상승 시간 t_r, 하강 시간 t_f**: 전압이 HIGH 레벨 전압의 **10%와 90% 사이**를 오가는 데 걸리는 시간.
  - ➕ 0~100%로 재지 않는 이유: 실제 파형은 시작과 끝 부분이 완만하게 휘어 있어서 정확한 시점을 잡기 어렵기 때문이다.
- **리딩 에지(leading edge)와 트레일링 에지(trailing edge)**: 각각 펄스의 시작 천이와 끝 천이.
  - 양 펄스에서는 리딩 에지가 상승(t_r)이고 트레일링 에지가 하강(t_f)이다.
  - **음 펄스에서는 리딩 에지가 하강(t_f)이고 트레일링 에지가 상승(t_r)이다.** "리딩 = 상승"이 아니다. (그림 5-14)
- **펄스 폭 t_w**: 리딩 에지와 트레일링 에지가 각각 HIGH 레벨의 **50%**를 지나는 두 점 사이의 시간.

## 5. 5.5 클럭 신호와 클럭 입력을 갖는 FF [5장 p.17–20]
- 디지털 시스템은 **동기(synchronous)** 방식이나 **비동기(asynchronous)** 방식으로 동작한다.
- 동기 시스템에서는 **클럭**이 출력이 바뀌는 시점을 정확히 정한다. 출력은 **클럭이 천이할 때에만** 바뀔 수 있다.
  - **PGT(positive-going transition)**: 클럭이 0에서 1로 바뀌는 천이 (상승 에지)
  - **NGT(negative-going transition)**: 클럭이 1에서 0으로 바뀌는 천이 (하강 에지)
- 대부분의 디지털 시스템은 동기 시스템이다. 동기화는 클럭 입력이 있는 FF로 구현한다.
- 동기 시스템의 동작 속도는 **클럭 주기**에 달려 있다.

### 클럭 입력을 갖는 FF의 특징 [p.18]
1. 클럭 입력은 CLK, CK, CP라고 부른다. 기호에는 **삼각형(▷)**을 그리고, NGT 트리거이면 버블을 더한다.
2. 하나 이상의 **제어 입력**(S, R, J, K, D 등)이 있다. 제어 입력은 클럭 에지가 오기 전에는 출력에 영향을 주지 않는다. 그래서 FF가 CLK에 **동기**된다. 이런 입력을 **동기 제어 입력**이라고 한다.
3. 제어 입력은 출력이 바뀔 **준비**만 하고, 실제 변화는 CLK의 활성 천이가 일으킨다.
   - 핵심 문장: **제어 입력은 '무엇'을, CLK는 '언제'를 정한다.**

### 셋업 시간과 홀드 시간 [p.19–20]
- **셋업 시간 t_S**: 클럭 에지가 **오기 전에** 제어 입력이 안정된 레벨을 유지해야 하는 최소 시간. 이 조건을 지키지 않으면 클럭 에지가 와도 FF가 제대로 응답하지 못한다.
- **홀드 시간 t_H**: 클럭 에지가 **지난 후에도** 동기 제어 입력이 안정된 레벨을 유지해야 하는 최소 시간.
- 정리하면 제어 입력은 클럭 에지 전 t_S부터 에지 후 t_H까지 바뀌면 안 된다. 이를 어긴 파형은 그림 5-19에 있다.

## 6. 5.6 클럭 입력을 갖는 S-R FF [5장 p.21–24]

### PGT 트리거 S-R FF [p.21]
상승 에지에서만 FF 상태가 바뀐다.

| S | R | CLK | Q |
|---|---|---|---|
| 0 | 0 | ↑ | Q₀ (변화 없음) |
| 1 | 0 | ↑ | 1 |
| 0 | 1 | ↑ | 0 |
| 1 | 1 | ↑ | 모호한 상태 (사용 안 함) |

- Q₀는 CLK 상승 에지 직전의 출력 레벨이다. **CLK 하강 에지에서는 Q가 전혀 바뀌지 않는다.**
- 예시 파형(그림 c): 상승 에지마다 변화 없음 → 세트 → 리셋 → 세트 → 세트 순서로 동작한다.

### NGT 트리거 S-R FF [p.22]
- 진리표는 위와 같고 CLK 열이 ↓다. 기호에서는 CLK 입력에 버블과 ▷가 함께 붙는다(그림 5-21).

### 에지 트리거 S-R FF의 내부 회로 [p.23] (그림 5-22)
세 부분으로 이루어진다.
1. **NAND 래치**: 게이트 3과 4. 입력은 SET̄, RESET̄
2. **펄스 구동 회로(pulse-steering circuit)**: NAND 게이트 1, 2
   - 게이트 1에는 S와 CLK*가 들어가 SET̄을 만든다.
   - 게이트 2에는 R과 CLK*가 들어가 RESET̄을 만든다.
3. **에지 검출 회로(edge-detector circuit)**: CLK에서 아주 짧은 펄스 CLK*를 만든다.

- 동작 예: S=1, R=0이면 CLK* 펄스가 NAND 1을 통과하면서 반전되어 래치의 SET̄에 **LOW 펄스**가 생긴다. 그 결과 Q=1로 세트된다.

### 에지 검출 회로 [p.24] (그림 5-23)
- **PGT용**: CLK와 CLK̄(인버터 출력)를 AND한다. 인버터의 전파 지연 때문에 CLK가 0에서 1로 올라간 직후 잠깐 동안 CLK와 CLK̄가 둘 다 1이 된다. 그래서 **상승 에지 직후에 좁은 펄스** CLK*가 나온다.
- **NGT용**: CLK와 CLK̄를 버블 입력 AND(= NOR)에 넣는다. CLK가 1에서 0으로 내려간 직후 둘 다 0인 짧은 구간이 생겨서 **하강 에지 직후에 좁은 펄스**가 나온다.
- ➕ 핵심: 펄스 폭은 **인버터의 전파 지연 시간**만큼이다.

## 7. 5.7 클럭 입력을 갖는 J-K FF [5장 p.25–26]
- **J = K = 1이면 클럭의 PGT마다 이전 상태가 반전된다.** 이를 **토글 모드(toggle mode)**라고 한다.
- 나머지 입력 조합에서는 S-R FF와 똑같이 동작한다. J는 S, K는 R에 해당한다.
- 즉 J-K FF는 S-R FF의 "모호한 상태"(11)를 토글로 바꿔 쓰는 FF다.

| J | K | CLK | Q |
|---|---|---|---|
| 0 | 0 | ↑ (또는 ↓) | Q₀ (변화 없음) |
| 1 | 0 | ↑ | 1 |
| 0 | 1 | ↑ | 0 |
| 1 | 1 | ↑ | Q̄₀ (토글) |

- 그림 5-24(b) 예시 파형은 a에서 리셋, c에서 토글, e에서 변화 없음, g에서 세트, i에서 토글, k에서 토글 순으로 동작한다.
- 그림 5-25는 NGT 트리거 J-K FF다. CLK에 버블이 있고 진리표의 CLK 열이 ↓다.

### 에지 트리거 J-K FF의 내부 회로 [p.26] (그림 5-26)
- S-R FF 내부 회로와 같고, 여기에 **피드백**이 더해진다.
  - NAND 1의 입력은 J, CLK*, **Q̄**다.
  - NAND 2의 입력은 K, CLK*, **Q**다.
- J = K = 1일 때 동작은 다음과 같다.
  - Q=0(Q̄=1)이면 NAND1 입력이 [1,1,1]이 되어 SET̄에 LOW 펄스가 생긴다. NAND2 입력은 [1,1,0]이라 RESET̄은 1을 유지한다. 그래서 **Q=1로 바뀐다**.
  - Q=1(Q̄=0)이면 NAND1 입력이 [0,1,1]이라 SET̄은 1을 유지한다. NAND2 입력은 [1,1,1]이 되어 RESET̄에 LOW 펄스가 생긴다. 그래서 **Q=0으로 바뀐다**.
- 결과적으로 클럭마다 토글한다. 피드백 덕분에 현재 상태의 반대쪽 게이트만 열린다.

---

## 8. 5.8 클럭 입력을 갖는 D FF [5장 p.27–28]
- 클럭 에지에서 **D 입력값이 그대로 Q가 된다**.

| D | CLK | Q |
|---|---|---|
| 0 | ↑ | 0 |
| 1 | ↑ | 1 |

- 그림 5-27(b) 파형: 상승 에지 a~g에서 각각 그 순간의 D 값을 Q에 저장한다. 에지와 에지 사이에 D가 바뀌어도 Q는 변하지 않는다.
- **J-K FF로 D FF 만들기**(그림 5-28): D를 J에 연결하고, D를 인버터에 통과시켜 K에 연결한다. 즉 J = D, K = D̄다.
  - D=1이면 J=1, K=0이므로 세트된다. D=0이면 J=0, K=1이므로 리셋된다.

### D FF를 이용한 2진수 병렬 전송 [p.28]
- 조합 회로의 출력 X, Y, Z를 D FF 3개의 D 입력에 연결하고, 모든 FF의 CLK에 공통 "전송" 신호를 넣는다. 그림에서는 NGT 트리거다.
- 전송 신호의 NGT가 오면 **X, Y, Z가 동시에** Q₁=X, Q₂=Y, Q₃=Z로 전달된다.

## 9. 5-18 직렬 데이터 전송과 시프트 레지스터 [5장 p.29–33]
- **시프트 레지스터(shift register)**: FF에 저장된 2진수가 클럭마다 한 FF에서 다음 FF로 이동하도록 연결한 FF들의 모음이다.
- 4비트 시프트 레지스터 구성(그림 a)
  - J-K FF 4개(X₃, X₂, X₁, X₀)를 NGT 트리거로 쓴다.
  - 데이터 입력은 X₃의 J에 그대로 들어가고, 인버터를 거쳐 K에도 들어간다(D FF처럼 동작).
  - 각 FF의 Q와 Q̄는 오른쪽 FF의 J와 K에 연결된다.
- NGT가 오면 각 FF의 출력은 **왼쪽 FF의 출력**(이것이 J와 K를 정한다)으로 결정된다. 그 값은 **NGT 바로 직전**의 출력이다.

### 예시 파형 (초기값 0000) [p.30]

| 시프트 펄스 | 직전 데이터 입력 | X₃ X₂ X₁ X₀ |
|---|---|---|
| 초기 | – | 0 0 0 0 |
| t1 | 1 | 1 0 0 0 |
| t2 | 0 | 0 1 0 0 |
| t3 | 1 | 1 0 1 0 |
| t4 | 1 | 1 1 0 1 |

### 홀드 시간 조건 [p.31]
- 시프트 레지스터에서는 J와 K 입력(앞 FF의 출력)이 **CLK 천이와 거의 같은 시각에** 바뀐다. 그래서 FF의 홀드 시간이 매우 짧아야 한다.
- 앞 FF의 출력은 NGT 후 **전파 지연**만큼 시간이 지나야 바뀐다. 그 짧은 시간 동안은 J와 K가 변하지 않는다.
- 따라서 **t_H < FF의 전파 지연(CLK에서 출력까지)**인 에지 트리거 FF로 시프트 레지스터를 만들어야 한다. 전파 지연이 홀드 시간보다 길어야 신뢰할 수 있는 출력이 나온다.

### 레지스터 사이의 직렬 전송 [p.32]
- 3비트 레지스터 X의 내용을 레지스터 Y로 직렬 전송하는 예.
- 데이터는 x₂ → x₁ → x₀ → y₂ → y₁ → y₀ 순서로 시프트된다.
- 3비트를 완전히 옮기려면 **시프트 펄스 3개**가 필요하다. 일반적으로 N비트를 옮기려면 펄스 N개가 필요하다.

### 병렬 전송과 직렬 전송 비교 [p.33]

| | 병렬 전송 | 직렬 전송 |
|---|---|---|
| 장점 | **빠르다** (클럭 1번에 모든 비트를 전송) | **경제적이고 회로가 간단하다** (선이 적다) |
| 단점 | 비트 수만큼 선이 필요하다 | 비트 수만큼 클럭이 필요해서 느리다 |

- 어느 방식을 고를지는 시스템의 응용 분야와 규격에 달려 있다.

## 10. 5.10 비동기 입력 [5추 p.3–5]
- **동기 입력**: CLK에 동기되어 시스템 출력에 영향을 준다(J, K, S, R, D).
- **비동기 입력**: 다른 입력 조건과 상관없이 **아무 때나** 영향을 준다.
  - 비동기 입력으로 FF를 1이나 0 상태로 만들 수 있고, 이때 **다른 모든 입력은 무시된다**. 그래서 **우선 입력(override input)**이라고 부른다.
- 대부분의 클럭 FF에는 클럭과 상관없이 동작하는 입력이 있다. 이름은 **PRE(PRESET)**와 **CLR(CLEAR)**이고, 보통 active-LOW(PRE̅, CLR̅)다.

### 비동기 입력이 있는 J-K FF (NGT 트리거) 진리표 [5추 p.4]

| J | K | Clk | PRE̅ | CLR̅ | Q |
|---|---|---|---|---|---|
| 0 | 0 | ↓ | 1 | 1 | Q (변화 없음) |
| 0 | 1 | ↓ | 1 | 1 | 0 (동기 리셋) |
| 1 | 0 | ↓ | 1 | 1 | 1 (동기 세트) |
| 1 | 1 | ↓ | 1 | 1 | Q̄ (동기 토글) |
| x | x | x | 1 | 1 | Q (변화 없음) |
| x | x | x | 1 | 0 | 0 (비동기 클리어) |
| x | x | x | 0 | 1 | 1 (비동기 프리셋) |
| x | x | x | 0 | 0 | 사용 안 함(Invalid) |

- PRE̅=0이면 FF 출력은 **항상 1에 묶인다**. CLR̅=0이면 **항상 0에 묶인다**.
- 비동기 입력은 FF를 원하는 기간 동안 특정 상태로 붙잡아 두는 데 쓴다.
- ➕ 동기 동작(J, K, CLK)이 정상적으로 되려면 PRE̅ = CLR̅ = 1(비활성)이어야 한다.

### 예제 파형 (J=K=1, NGT 트리거) [5추 p.5]

| 위치 | 동작 |
|---|---|
| a | CLK의 NGT에서 동기 토글 (1 → 0) |
| b | PRE̅ = 0이므로 비동기 세트 (클럭 에지와 무관하게 즉시 1) |
| c | 동기 토글 (1 → 0) |
| d | 동기 토글 (0 → 1) |
| e | CLR̅ = 0이므로 비동기 클리어 (즉시 0) |
| f | **CLR̅이 CLK의 NGT를 오버라이드한다.** CLR̅=0이 유지되는 동안에는 NGT가 와도 토글하지 않는다 |
| g | 동기 토글 (0 → 1) |

## 11. FF의 응용 [5추 p.6–10]

### 5.13 플립플롭의 응용 [5추 p.6]
- FF는 카운팅, 2진 데이터 저장, 레지스터 사이의 2진 데이터 전송에 쓴다.
- FF의 클럭 동작은 대부분 **순차 회로**에 쓰인다.
  - 순차 회로는 미리 정해진 상태(state) 순서에 따라 출력이 바뀌고, 클럭이 올 때마다 새 상태로 넘어간다.

### 5.14 플립플롭의 동기화 [5추 p.7–8]
- 순차 회로의 신호는 대부분 클럭 천이에 맞춰 바뀌므로 디지털 시스템은 기본적으로 동기화되어 있다. 하지만 클럭과 동기되지 않은 외부 신호, 즉 **비동기 신호**도 많다.
- 문제 상황: 디바운스된 스위치 출력 A와 CLOCK을 그냥 AND로 묶어 X를 만든다. A가 클럭과 상관없는 시각에 바뀌므로 X의 처음과 끝에 **잘린 펄스(partial pulse)**가 생길 수 있다. 부분 펄스는 허용되지 않는다.
- 해결: **에지 트리거 D FF로 A를 동기화**한다.
  - A를 D 입력에, 클럭을 CLK에 넣는다(그림에서는 NGT 트리거). 그리고 Q와 클럭을 AND해서 X를 만든다.
  - Q는 클럭의 NGT(t1, t2)에서만 바뀐다. 그러면 클럭이 LOW인 동안 AND가 열리고 닫히므로 X에는 **완전한 펄스만** 나온다.

### 5.15 입력 순차 검출 [5추 p.9]
- D FF를 이용하면 두 신호 중 어느 것이 먼저 바뀌었는지 검출할 수 있다.
- 어떤 경우에는 입력이 정해진 순서대로 활성화되어야만 출력이 활성화된다. 이 기능은 순수 조합 회로로는 만들 수 없고, **FF의 저장 특성**이 필요하다.
  - Q = A·B 같은 조합 회로로는 A와 B 중 어느 쪽이 먼저 HIGH가 되었는지 알 수 없다.
- 회로: A를 D에, B를 CLK(PGT)에 연결한다.
  - (b) A가 B보다 먼저 HIGH가 되면 B의 상승 에지에서 D=1이므로 **Q=1**이 된다.
  - (c) B가 A보다 먼저 HIGH가 되면 B의 상승 에지에서 D=0이므로 **Q=0**에 머문다.

### 5.16 천이 또는 "이벤트" 검출 [5추 p.10]
- 논리 상태의 변화를 천이, 에지, 이벤트라고 부른다. 이런 변화가 생기면 논리 회로가 반응해야 할 때가 있다.
- 회로: 입력 신호를 D FF(PGT)의 D에 넣고, **입력 신호와 Q를 XOR**해서 Edge 출력을 만든다.
  - 입력과 Q(마지막 클럭 에지 때 저장된 입력값)가 다르면 Edge = 1이다. 즉 **지난번 클럭 에지 이후 입력이 바뀌었다**는 뜻이다.
  - t1, t2, t3에서는 입력이 LOW이고 지난 에지 이후 바뀌지 않았으므로 Edge = 0이다.
  - t3와 t4 사이에 입력이 바뀌면 Edge = 1이 되고, 다음 클럭 에지(t4)에서 Q가 입력을 따라잡으면 Edge = 0으로 돌아간다. 입력이 다시 떨어질 때(t6 부근)도 같은 방식으로 짧은 Edge 펄스가 생긴다.

## 12. 5.19 주파수 분할과 카운터 [5추 p.11–13]

### 주파수 분할 [5추 p.11]
- 회로: J = K = 1(토글)인 NGT J-K FF 3개(모든 PRE̅와 CLR̅은 HIGH)를 연결한다. 입력 클럭은 Q₀의 CLK에 들어가고, Q₀는 Q₁의 CLK에, Q₁은 Q₂의 CLK에 들어간다.
  1. Q₀는 입력 클럭의 NGT마다 토글하므로 Q₀의 주파수는 **클럭의 1/2**이다.
  2. Q₁은 Q₀ 주파수의 1/2이다.
  3. Q₂는 Q₁ 주파수의 1/2이다.
- FF 4개를 연결하면 1/16, **n개를 연결하면 1/2ⁿ** 주파수가 된다. 이런 응용을 **주파수 분할**이라고 한다.

### 카운터 동작 [5추 p.12]
- 같은 회로가 **2진 카운터**로 동작한다. 클럭 펄스마다 Q₂Q₁Q₀는 다음과 같이 바뀐다.

| 클럭 | Q₂ Q₁ Q₀ |
|---|---|
| 펄스 전 | 000 |
| #1 후 | 001 |
| #2 후 | 010 |
| #3 후 | 011 |
| #4 후 | 100 |
| #5 후 | 101 |
| #6 후 | 110 |
| #7 후 | 111 |
| #8 후 | 000 (리사이클) |
| #9, #10, #11 후 | 001, 010, 011 |

### 상태 천이도 [5추 p.13]
- FF 상태가 어떻게 바뀌는지 나타내는 그림이다.
  - 각 원 안에는 상태 하나를 2진수로 쓴다.
  - 화살표는 클럭 펄스가 들어왔을 때 한 상태에서 다른 상태로 넘어가는 것을 나타낸다.
- 카운터나 다른 순차 회로를 설계, 분석, 설명할 때 쓴다.
- 3비트 카운터: 000 → 001 → 010 → 011 → 100 → 101 → 110 → 111 → 000 (원형)
- **MOD 수(모드 수)**: 카운터 순서에 들어 있는 논리 상태의 개수. 위 예는 MOD-8이다.

## 13. 수업 요약 [5장 p.34]
- FF는 신호를 저장할 수 있다.
- FF는 클럭 에지 때 들어온 입력을 바탕으로 출력을 정한다.
- S-R FF는 set 입력과 reset 입력을 받는다.
- J-K FF는 S-R FF와 거의 같고, J=K=1(S=R=1에 해당)일 때 토글한다.
- D FF는 입력값을 그대로 출력한다.

## 시험 포인트 / 헷갈리는 것
- **NAND 래치와 NOR 래치**: NAND는 active-LOW이고 금지 입력이 00(Q=Q̄=1)이다. NOR는 active-HIGH이고 금지 입력이 11(Q=Q̄=0)이다. 유지 입력은 NAND가 11, NOR가 00이다.
- NAND 래치에서 SET=CLEAR=1이면 출력 상태가 **두 가지 모두 가능**하다. 어느 쪽인지는 이전 상태가 정한다.
- 금지 입력에서 동시에 HIGH로 돌아가면 **결과를 예측할 수 없다**. 하나씩 돌아가면 나중에 돌아간 쪽 입력이 결과를 정한다.
- 디바운스가 되는 이유: 바운스 때 입력이 11, 즉 "변화 없음"이 되기 때문이다.
- 상승/하강 시간은 **10~90%** 구간, 펄스 폭은 **50%** 지점 사이로 잰다. 음 펄스의 리딩 에지는 하강 에지다.
- 셋업 시간은 에지 **전**, 홀드 시간은 에지 **후**에 입력이 안정되어 있어야 하는 시간이다.
- 제어 입력은 "무엇", CLK는 "언제"를 정한다.
- 에지 검출기는 인버터 지연을 이용한다. PGT용은 AND(CLK, CLK̄), NGT용은 NOR 형태(버블 입력 AND)다.
- J-K 내부 회로의 토글은 **Q와 Q̄를 펄스 구동 NAND로 되먹이는 피드백** 덕분이다. NAND1에는 Q̄가, NAND2에는 Q가 들어간다.
- D FF를 J-K로 만들려면 J=D, K=D̄로 연결한다.
- 시프트 레지스터가 제대로 동작하려면 **t_H < 전파 지연**이어야 한다. N비트 직렬 전송에는 시프트 펄스 N개가 필요하다.
- 병렬 전송은 빠르고, 직렬 전송은 경제적이고 회로가 간단하다.
- PRE̅와 CLR̅는 **비동기(우선) 입력**이라 클럭을 무시하고 바로 동작한다. 둘 다 0이면 무효다. CLR̅이 LOW인 동안 오는 NGT는 무시된다.
- 동기화 D FF는 비동기 신호를 클럭에 맞춰서 **부분 펄스**를 없앤다.
- 입력 순차 검출: Q=1이면 D(A)가 CLK(B)보다 **먼저** HIGH가 된 것이다.
- 이벤트 검출은 **입력 ⊕ Q**로 한다. 지난 에지 이후 입력이 바뀌었으면 1이 된다.
- 토글 FF n개를 연결하면 주파수가 **1/2ⁿ**로 나뉘고, MOD-2ⁿ 카운터가 된다.
