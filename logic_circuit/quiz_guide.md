# 논리회로 퀴즈 출제 가이드

퀴즈를 새로 만들 때마다 이 파일을 먼저 읽고 따른다.

## 출제 규칙

- 출제 범위: 이 폴더의 강의 자료 전체 (아래 **제외 범위**는 빼고)
  - 중간: `midterm_chapters/*.pdf`
  - 기말: `final_sum/5장_요약.md`, `7장_요약.md`, `9장_요약.md` — 원본 PDF(`final_chapters/`)는 2026-11-26 요약 후 `TRASH/final_chapters/`로 옮김. PDF 대신 이 요약본을 읽고 출제한다. 요약의 `[5장 p.N]`, `[5추 p.N]`(5장 추가), `[7장 p.N]`, `[7-2 p.N]`(7장 part2), `[9장 p.N]` 태그가 원본 쪽 번호다. `➕` 표시는 강의노트 외 보충이므로 출제 근거로 쓰지 않는다
- 챕터 순서: 랜덤으로 섞는다
- 문제 형식: T/F, 회로 그리기, 개념 체크, 객관식, 주관식 등 모두 가능. 형식 순서도 랜덤
- 난이도: 어렵게
- 카운터 설계 문제(상태표 → 여기표 → K-map): **FF(비트) 2개까지만** 출제한다. 3비트 이상은 너무 오래 걸림 (2026-11-26 사용자 요청, quiz_2 Q4 계기)
- 문제 파일: `.md` (VS Code 미리보기로 풀이). PDF 요청 시 같은 이름의 `.pdf`도 만든다 (md → HTML → Chrome headless `--print-to-pdf`, 아래첨자 숫자는 폰트에 없는 글리프가 있어 `<sub>`로 변환)
- 정답: 문제 파일과 별도 파일로 저장
- 해설: 문제 파일·정답 파일에 쓰지 않는다. 사용자가 모르는 문제를 물어볼 때만 채팅으로 설명
- 기록: 사용자가 물어본 문제·해설을 마음대로 파일에 기록하지 않는다. 사용자가 **기록하라고 한 문제만** 기록한다
- 이전 퀴즈와 문제가 중복되지 않게 한다
- 파일 위치: `quiz/quiz_N.md`(문제), `quiz/quiz_N_answer.md`(정답), 기록 요청 문항은 `quiz/quiz_N_wrong.md`(해설 포함), 전체 해설을 요청하면 `quiz/quiz_N_explanation.md`

## 제외 범위 (출제 금지)

| 자료                       | 제외 페이지 | 비고                                      |
|----------------------------|-------------|-------------------------------------------|
| `논리회로 4장 (1) (1).pdf` | 49쪽        | 연결되지 않은(floating) 입력 — 퀴즈 1 Q14 |
| `논리회로 9장.pdf`         | 13쪽 ~ 끝   | **중간고사만** 해당 (기말은 9장 전체 출제) |
| `7장 - part2` (`[7-2 …]`)  | 7.7절, 7-11~7-13절, 7-15·7-16절 | 강의노트에 "범위에서 제외"로 명시 — 요약본에도 내용 없음 |

- 사용자가 "여기 시험 범위 아니야"라고 하면 위 표에 추가한다.
