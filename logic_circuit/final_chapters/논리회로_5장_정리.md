## 한눈에 보기

**래치(기억) → 클럭 추가(타이밍 제어) → S-R / J-K / D 플립플롭 → 플립플롭을 연결한 데이터 전송**

- 플립플롭은 **1비트를 저장**합니다.
- 클럭이 있는 플립플롭은 **클럭 에지 순간의 입력**으로 다음 출력을 정합니다.
- 제어입력은 **무엇**을, 클럭은 **언제**를 결정합니다.

## 1. 플립플롭의 기본 (p.3–4)

디지털 시스템은 기억소자와 조합논리회로로 구성됩니다. 플립플롭(FF)은 논리게이트를 조합해 만든 기억소자입니다.

| 용어 | 의미 |
|---|---|
| Q | 정상 출력 |
| Q̄ | 반전 출력. 항상 Q의 반대 |
| 세트(Set) | Q=1, HIGH 상태 |
| 클리어(Clear) = 리셋(Reset) | Q=0, LOW 상태 |

조합회로와의 차이는 다음과 같습니다. (보충)

| | 조합회로 | 순서회로(플립플롭 포함) |
|---|---|---|
| 출력을 정하는 것 | 현재 입력 | 현재 입력 + **저장된 상태** |
| 기억 능력 | 없음 | 있음 |

슬라이드는 래치와 플립플롭을 같은 말로 소개합니다(p.4). 다만 보통은 다음처럼 구분해서 부릅니다. (보충)

- **래치:** 입력 레벨에 반응
- **플립플롭:** 클럭 에지에 반응

## 2. NAND 게이트 래치 (p.5–12)

### 동작 표

입력은 **LOW일 때 동작**합니다(active-LOW).

| SET | CLEAR | 출력 | 이름 |
|---|---|---|---|
| 1 | 1 | 변화 없음 | 유지 |
| 0 | 1 | Q=1 | 세트 |
| 1 | 0 | Q=0 | 클리어 |
| 0 | 0 | Q=Q̄=1 | **사용 안 함** |

### 왜 기억할 수 있을까? (보충)

연결 구조는 다음과 같습니다.

```text
Q  = NAND(SET,   Q̄)
Q̄  = NAND(CLEAR, Q)
```

NAND는 입력에 0이 하나라도 있으면 출력이 1입니다. 이를 이용해 세트 과정을 따라가 보겠습니다.

| 단계 | 입력 | 일어나는 일 | 결과 |
|---|---|---|---|
| 1 | SET=0, CLEAR=1 | SET=0이므로 Q=NAND(0, Q̄)=1 | Q=1 |
| 2 | 입력 동일 | Q̄=NAND(1, 1)=0 | Q̄=0 |
| 3 | SET=1로 복귀 | Q=NAND(1, 0)=1 | **Q=1 유지** |

3단계에서 SET 펄스가 사라져도, Q̄=0이 되돌아와 Q를 1로 붙잡아 둡니다. 이 **피드백**이 기억의 원리입니다.

### 금지 입력 SET=CLEAR=0 (p.8)

- 두 출력이 모두 1이 되어 "Q̄는 Q의 반대"라는 전제가 깨집니다.
- 이후 출력은 어떤 입력이 먼저 HIGH로 돌아가는지에 따라 달라집니다.
- 두 입력이 동시에 HIGH가 되면 출력을 예측할 수 없습니다.

### 디바운스 회로 (p.12)

기계식 스위치는 접점이 닿는 순간 여러 번 튀어(바운스), 신호가 짧게 여러 번 변합니다.

1. 스위치가 한 접점에 닿으면 래치가 세트 또는 클리어됩니다.
2. 접점에서 튀어 떨어지는 동안에는 두 입력이 모두 HIGH(유지 상태)가 됩니다.
3. 따라서 출력은 흔들리지 않습니다.

## 3. NOR 게이트 래치 (p.13–14)

입력은 **HIGH일 때 동작**합니다(active-HIGH).

| SET | CLEAR | 출력 | 이름 |
|---|---|---|---|
| 0 | 0 | 변화 없음 | 유지 |
| 1 | 0 | Q=1 | 세트 |
| 0 | 1 | Q=0 | 클리어 |
| 1 | 1 | Q=Q̄=0 | **사용 안 함** |

> **슬라이드 오타로 보이는 부분 (p.13):** 3번 항목의 "CLEAR 신호가 1이 되어도 LOW를 유지"는 "**0으로 되돌아가도**"가 맞는 것으로 보입니다.

### NAND와 NOR 비교

| | NAND 래치 | NOR 래치 |
|---|---|---|
| 동작 입력 | 0 | 1 |
| 유지 | 11 | 00 |
| 세트 (SET, CLEAR) | 01 | 10 |
| 클리어 (SET, CLEAR) | 10 | 01 |
| 금지 | 00 | 11 |
| 금지 입력일 때 출력 | 둘 다 1 | 둘 다 0 |

**외우는 법:** NAND는 0이 하나라도 있으면 1이 나오므로 0에 반응합니다. NOR는 1이 하나라도 있으면 0이 나오므로 1에 반응합니다.

## 4. 디지털 펄스 (p.15)

| 용어 | 정의 |
|---|---|
| 양 펄스 | 평소 LOW → 잠깐 HIGH |
| 음 펄스 | 평소 HIGH → 잠깐 LOW |
| 리딩 에지 | 펄스가 시작될 때의 천이 |
| 트레일링 에지 | 펄스가 끝날 때의 천이 |
| 상승시간 tr / 하강시간 tf | HIGH 레벨 전압의 **10%와 90%** 사이를 변하는 시간 |
| 펄스폭 tw | 리딩 에지와 트레일링 에지의 **50%** 지점 사이 시간 |

## 5. 클럭 (p.17–20)

### 동기 시스템

- **동기 시스템:** 클럭에 맞춰 출력이 변합니다. 대부분의 디지털 시스템이 이 방식입니다.
- 시스템의 동작 속도는 클럭 주기에 의존합니다.
- **PGT:** 클럭 0→1 (상승 에지)
- **NGT:** 클럭 1→0 (하강 에지)

### 셋업시간과 홀드시간

```text
              클럭 에지
                  |
      <--- ts --->|<- tH ->
       입력 유지    입력 유지
```

| | 위치 | 의미 |
|---|---|---|
| 셋업시간 ts | 에지 **전** | 입력이 미리 안정되어 있어야 하는 시간 |
| 홀드시간 tH | 에지 **후** | 입력이 계속 유지되어야 하는 시간 |

이 시간을 어기면 클럭 에지가 발생해도 플립플롭이 제대로 응답한다고 보장할 수 없습니다.

## 6. 클럭 플립플롭 (p.21–28)

### 동작 표

Q는 에지 직전의 값이고, 출력은 **활성 에지에서만** 바뀝니다.

| 입력 | S-R | J-K |
|---|---|---|
| 00 | 유지 | 유지 |
| 10 | 1 (세트) | 1 (세트) |
| 01 | 0 (클리어) | 0 (클리어) |
| 11 | **사용 안 함** | **토글** |

| D | 에지 후 Q |
|---|---|
| 0 | 0 |
| 1 | 1 |

### 특성 방정식 (보충)

다음 상태 Q(next)를 식으로 나타낸 것입니다.

```text
S-R : Q(next) = S + R̄·Q   (단, S·R = 0)
J-K : Q(next) = J·Q̄ + K̄·Q
D   : Q(next) = D
```

### 여기표 (보충)

"Q를 이렇게 바꾸려면 입력을 어떻게 줘야 하는가"를 나타낸 표입니다. X는 0과 1 어느 쪽이든 상관없다는 뜻입니다.

| Q → Q(next) | S R | J K | D |
|---|---|---|---|
| 0 → 0 | 0 X | 0 X | 0 |
| 0 → 1 | 1 0 | 1 X | 1 |
| 1 → 0 | 0 1 | X 1 | 0 |
| 1 → 1 | X 0 | X 0 | 1 |

### S-R 내부 회로 (p.23)

| 구성 요소 | 역할 |
|---|---|
| 에지검출회로 | 클럭 에지에서 아주 짧은 펄스를 생성 |
| 펄스구동회로 | S, R 값에 따라 펄스를 래치의 세트 또는 리셋 쪽으로 전달 |
| NAND 래치 | 값을 저장 |

**예시:** S=1, R=0이면 펄스가 세트 쪽 NAND를 통과하며 반전되어 래치의 SET 입력에 LOW 펄스가 들어갑니다. 그 결과 Q=1이 됩니다.

### J-K 토글 원리 (p.26)

J-K는 현재 출력을 입력 쪽으로 되먹입니다. 그래서 J=K=1이면 현재 값에 따라 두 NAND 중 하나만 동작합니다.

| 현재 Q | 세트 쪽 NAND | 리셋 쪽 NAND | 결과 |
|---|---|---|---|
| 0 | [1,1,1] → LOW 펄스 | 1 유지 | Q=1 |
| 1 | 1 유지 | [1,1,1] → LOW 펄스 | Q=0 |

**토글의 활용 (보충):** 클럭마다 값이 뒤집히면 Q의 주기는 클럭 주기의 2배입니다. 즉 **주파수가 절반**이 되며, 이것이 카운터와 주파수 분주기의 기본 원리입니다.

### D 플립플롭 (p.27)

- J-K 플립플롭에 인버터를 더해 만들 수 있습니다: **J=D, K=D̄** (보충)
- 이렇게 연결하면 J와 K가 항상 반대이므로 유지나 토글이 일어나지 않고, 금지 입력도 생기지 않습니다.
- 요약 슬라이드의 "입력 값을 그대로 내보낸다"는 **에지 순간의 값이 반영된다**는 뜻입니다. 에지 사이에 D가 변해도 Q는 그대로입니다.

### 비동기 입력 (보충)

슬라이드에 없는 내용입니다. 많은 플립플롭에는 클럭과 상관없이 출력을 바로 정하는 입력이 있습니다.

- **PRESET:** 즉시 Q=1
- **CLEAR:** 즉시 Q=0
- 동기 입력보다 우선하며, 주로 회로를 초기화할 때 씁니다.

## 7. 파형 그리기

### 풀이 순서

1. 활성 에지가 **PGT인지 NGT인지** 확인합니다. 기호의 클럭 입력에 동그라미가 있으면 보통 NGT입니다.
2. 활성 에지마다 세로줄을 긋습니다.
3. 각 줄에서 입력 값을 읽습니다. **줄 사이의 변화는 무시합니다.**
4. 동작 표로 다음 Q를 정합니다.
5. Q는 다음 활성 에지까지 그대로 유지합니다.

### 예시 1: D 플립플롭, PGT, 초기 Q=0

`#`은 HIGH, `_`는 LOW, `^`는 PGT 위치입니다.

```text
CLK : __##__##__##__##__
        ^   ^   ^   ^
D   : ####___##___######
Q   : __####________####
```

| 에지 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| D | 1 | 0 | 0 | 1 |
| Q | 1 | 0 | 0 | 1 |

2번째와 3번째 에지 사이에 D가 잠깐 HIGH가 되지만, 에지 순간의 값이 아니므로 Q는 변하지 않습니다.

### 예시 2: J-K 플립플롭, 초기 Q=0

| 에지 | J | K | 동작 | Q |
|---|---|---|---|---|
| 1 | 1 | 0 | 세트 | 1 |
| 2 | 1 | 1 | 토글 | 0 |
| 3 | 0 | 0 | 유지 | 0 |
| 4 | 1 | 1 | 토글 | 1 |
| 5 | 0 | 1 | 클리어 | 0 |
| 6 | 1 | 0 | 세트 | 1 |

## 8. 데이터 전송 (p.28–33)

### 병렬 전송

비트마다 D 플립플롭을 하나씩 두고, X, Y, Z 값을 클럭 한 번에 X′, Y′, Z′로 **동시에** 옮깁니다.

### 직렬 전송: 시프트 레지스터

각 플립플롭이 클럭마다 앞 플립플롭의 값을 받아 한 칸씩 이동합니다.

**예시:** 레지스터 X=101을 Y로 전송합니다. 경로는 X2→X1→X0→Y2→Y1→Y0이고, X2의 입력은 0으로 가정했습니다.

| 클럭 | X2 X1 X0 | Y2 Y1 Y0 |
|---|---|---|
| 시작 | 1 0 1 | 0 0 0 |
| 1번째 | 0 1 0 | 1 0 0 |
| 2번째 | 0 0 1 | 0 1 0 |
| 3번째 | 0 0 0 | **1 0 1** |

### 값이 한 번에 여러 칸 건너뛰지 않는 이유 (p.31)

1. 모든 플립플롭이 같은 클럭 에지를 받습니다.
2. 출력은 에지 후 **전파지연**만큼 늦게 변합니다.
3. 전파지연이 **홀드시간보다 길면**, 다음 플립플롭은 앞단의 **에지 직전 값**을 받습니다.

그래서 값이 클럭마다 정확히 한 칸씩 이동합니다.

### 병렬과 직렬 비교

| | 병렬 | 직렬 |
|---|---|---|
| N비트 전송에 필요한 클럭 | 1번 | N번 |
| 데이터 선 | N개 | 1개 |
| 장점 | 빠름 | 회로가 간단하고 경제적 |

어떤 방식을 고를지는 시스템의 응용분야와 규격에 따라 달라집니다.

## 9. 자주 하는 실수

| 실수 | 바른 이해 |
|---|---|
| NAND 래치도 1을 넣어야 세트된다고 생각함 | NAND 래치는 **SET=0**일 때 세트 |
| 에지 사이의 입력 변화도 Q에 반영함 | 클럭 플립플롭은 **활성 에지 순간의 입력**만 봄 |
| PGT와 NGT를 확인하지 않고 파형을 그림 | 에지 종류부터 확인 |
| 셋업과 홀드를 반대로 외움 | 셋업은 에지 **전**, 홀드는 에지 **후** |
| J=K=1을 S-R처럼 금지 입력으로 처리함 | J-K에서는 **토글** |
| 10%, 90%, 50% 기준을 혼동함 | tr·tf는 10%–90%, tw는 50%–50% |

## 10. 확인 문제

### 문제

1. 처음에 Q=0인 **NAND 래치**에 (SET, CLEAR)가 (1,1) → (0,1) → (1,1) → (1,0) → (1,1) 순서로 들어옵니다. 각 단계의 Q는?
2. 처음에 Q=0인 **NOR 래치**에 (SET, CLEAR)가 (1,0) → (0,0) → (0,1) → (0,0) 순서로 들어옵니다. 각 단계의 Q는?
3. 처음에 Q=1인 **NGT J-K 플립플롭**의 하강 에지에서 (J, K)가 (0,0), (1,1), (1,0), (0,1), (1,1) 순서로 입력됩니다. 각 에지 후의 Q는?
4. 처음에 Q=0인 PGT D 플립플롭의 상승 에지에서 D가 1, 1, 0, 1입니다. 각 에지 후의 Q는?
5. 처음에 0000인 4비트 오른쪽 시프트 레지스터에 직렬 입력 1, 0, 1, 1을 차례로 넣습니다. 각 클럭 후의 값은?
6. HIGH 레벨이 5V인 펄스에서 상승시간과 펄스폭을 측정하는 기준 전압은?
7. ts=20ns, tH=5ns이고 클럭 에지가 t=100ns에 발생합니다. 입력은 언제부터 언제까지 변하면 안 될까요?
8. J=K=1인 플립플롭에 1MHz 클럭을 넣으면 Q의 주파수는?
9. 1MHz 클럭으로 8비트를 전송할 때, 병렬과 직렬의 전송 시간은 각각 얼마일까요?

## 11. 시험 전 체크리스트

- [ ] NAND / NOR 래치 표를 보지 않고 쓸 수 있다.
- [ ] 래치가 값을 기억하는 원리를 피드백으로 설명할 수 있다.
- [ ] tr, tf, tw의 측정 기준을 안다.
