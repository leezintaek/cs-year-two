래치 플립플롭은 이전에 배운 논리회로에 기억소자를 추가한다고 생각하면 됩니다.
일반적인 디지털 시스템은 기억소자와 조합논리회로로 구성되는데, 플립플롭은 논리게이트를 조합해 만든 기억소자입니다. Q̄는 항상 Q의 반전입니다.
먼저 간단하게 래치 플립플롭은 SET와 CLEAR(=RESET) 입력을 가집니다.
NAND 게이트로 구성한 플립플롭은
set 1 clear 1 변화 없음
set 1 clear 0 Q = 0 (클리어/리셋)
set 0 clear 1 Q = 1 (세트)
set 0 clear 0 사용 안됨
와 같은 진리표를 가집니다. 회로 사진과 같이 봤을 때 이해가 잘 안될텐데, 평소에 두 입력 모두 1 1 을 유지한 상태일 때 어떤 Q가 출력되고 있을 것입니다. (SET=CLEAR=1일 때는 Q=0, Q=1 두 출력상태가 모두 가능합니다.)
그때 잠깐 set나 clear가 0을 가지면 출력이 유지되거나 변화한다고 생각하면 이해가 쉽습니다. 입력이 다시 1로 돌아와도 출력이 피드백으로 되돌아와 값을 붙잡고 있기 때문에 바뀐 값이 유지됩니다. 이것이 기억의 원리입니다.
두 입력 값이 00 일 때는 사용이 되지 않습니다. 둘 다 0이면 Q=Q̄=1이 되고, 다시 1로 돌아갈 때 어느 입력이 먼저 HIGH가 되느냐에 따라 결과가 달라져서(동시에 HIGH가 되면 결정 불가) 출력을 예측할 수 없기 때문입니다.

디바운스 회로
기계적 스위치는 접점이 닿을 때 여러 번 튀는(바운스) 현상이 생깁니다. NAND 래치를 쓰면 스위치가 튀어서 두 입력이 모두 1이 되어도 "변화 없음" 상태이므로 출력이 흔들리지 않습니다. 이것을 디바운스 회로라고 합니다.

NOR 게이트 래치
NOR 래치는 NAND 래치와 반대로 입력이 HIGH일 때 동작합니다(동적 HIGH).
set 0 clear 0 변화 없음
set 1 clear 0 Q = 1
set 0 clear 1 Q = 0
set 1 clear 1 사용 안됨 (Q=Q̄=0)

디지털 펄스
펄스는 신호가 평소의 비활성 상태에서 반대 상태로 잠깐 바뀌었다가 돌아오는 것인데, 돌아온 뒤에도 그 영향이 시스템에 남아 있는 신호입니다.
간단하게 용어를 그림과 같이 이해하면 편합니다. 양 펄스는 평소 LOW였다가 HIGH로 변할 때 기능이 수행되고, 음 펄스는 평소 HIGH였다가 LOW로 변할 때 기능이 수행됩니다.
상승시간과 하강시간은 HIGH 레벨 전압의 10%~90% 사이를 이동하는 시간을 의미하는데, 0-100이 아닌 이유는 펄스가 이상적으로 수직으로 움직이지 않고 시작과 끝 부분이 완만하게 휘어 있어서 정확한 시점을 잡기 어렵기 때문에, 비교적 곧게 변하는 10-90 구간으로 측정합니다.
리딩 에지와 트레일링 에지는 각각 펄스의 시작과 끝에 있는 천이를 가리킵니다. 리딩 에지라고 상승 에지를 의미하는 건 아닙니다. 양 펄스에서는 리딩 에지가 상승 에지이지만, 음 펄스에서는 리딩 에지가 하강 에지입니다.
펄스 폭은 리딩 에지와 트레일링 에지가 50%를 가리키는 두 지점 사이의 시간입니다.

동기와 비동기에서, 동기란 클럭이 천이할 때에만 출력이 변하는 회로를 의미하며, 비동기는 앞의 래치처럼 입력이 바뀌면 클럭과 상관없이 바로 출력이 바뀌는 회로입니다. 대부분의 디지털 시스템은 동기 방식이고, 동기 시스템의 동작 속도는 클럭 주기에 의존합니다.
클럭에는 PGT(0→1, 상승 에지)와 NGT(1→0, 하강 에지)가 존재하는데, 회로에서 CLK 입력에 삼각형만 존재하면 PGT이며, 동그라미가 같이 있다면 NGT입니다.
동기에서는 클럭에 의해 출력이 변화할 수 있습니다. 클럭이 HIGH나 LOW로 유지되는 동안에는 출력이 변하지 않고, 클럭의 에지(천이) 순간에만 제어 입력에 의해 출력이 변화합니다.
클럭은 CLK로 부르겠습니다. (CK, CP라고도 씁니다.)
간단하게 제어입력은 '무엇'을 CLK는 '언제'를 의미한다고 생각하면 편합니다. 제어입력은 클럭 에지가 오기 전에는 출력에 영향을 주지 않으므로 동기제어입력이라고 부릅니다.
제어입력에는 클럭 에지를 기준으로 셋업시간과 홀드시간이 존재하는데, 셋업시간(ts)은 클럭 에지 전에 미리 준비되어서 유지해야 하는 시간이며, 홀드시간(tH)은 클럭 에지 후에 플립플롭이 입력을 다 읽을 때까지 유지되어야 하는 짧은 시간입니다. 이때 유지되어야 한다고 하는 것은 제어입력입니다. 이 조건을 어기면 클럭 에지가 와도 플립플롭이 제대로 응답한다고 보장할 수 없습니다.

플립플롭을 S-R, J-K, D 순으로 배워보겠습니다.
S-R 플립플롭은 처음 배운 래치에 CLK가 존재한다고 생각하면 됩니다. 클럭 에지에서만 동작합니다. (진리값 사진) (변화 사진)
S=0 R=0 변화 없음
S=1 R=0 Q = 1
S=0 R=1 Q = 0
S=1 R=1 사용 안됨
에지 트리거 S-R FF는 NAND 래치(NAND 2개), 펄스구동회로(NAND 2개), 에지검출회로의 세 부분으로 구성됩니다. 즉 NAND 4개에 에지검출회로를 더한 구조입니다.
에지검출회로는 인버터의 지연을 이용해서 CLK와 CLK̄가 잠깐 같은 값이 되는 순간에 아주 짧은 펄스(CLK*)를 만듭니다. PGT용은 AND 게이트, NGT용은 입력에 동그라미가 붙은 AND 게이트를 씁니다. 이 짧은 펄스가 S, R 값에 따라 래치의 SET 쪽이나 RESET 쪽으로 전달됩니다. 예를 들어 S=1, R=0이면 펄스가 NAND1을 지나며 반전되어 래치의 SET에 LOW 펄스가 들어가고 Q=1이 됩니다.

J-K FF는 S-R에서 두 입력값이 11 일 때 사용하지 않는 비효율성을 해결하기 위한 진화 버전입니다. J=K=1이면 클럭 에지마다 이전 상태의 반대가 되는데, 이를 토글 모드라고 합니다. 나머지 입력은 S-R과 같습니다.
아까 S-R의 회로에서 출력 Q를 K 쪽 펄스구동 NAND(NAND2)에, Q̄를 J 쪽 펄스구동 NAND(NAND1)에 되먹임하는 것으로 만들 수 있습니다. (사진)
그래서 J=K=1일 때 Q=0이면 NAND1만 열려 세트되고, Q=1이면 NAND2만 열려 리셋되므로 토글이 됩니다.

D FF는 하나의 입력으로 만들 수 있는 회로이며, 클럭 에지에서 D=1 일 때 Q는 1이고 D=0일 때 Q 는 0입니다.
이는 J-K 플립플롭의 J에 D를, K에 인버터를 거친 D̄를 연결해서 구성 가능합니다 (사진)

데이터 전송
병렬 전송은 비트마다 D FF를 하나씩 두고 CLK를 공통으로 연결해서, 클럭 에지 한 번에 X, Y, Z 값을 X*, Y*, Z*로 동시에 옮기는 방식입니다.
직렬 전송은 시프트 레지스터를 사용합니다. 시프트 레지스터는 각 FF가 왼쪽 FF의 출력을 입력으로 받도록 연결되어 있어서, 클럭마다 저장된 값이 한 칸씩 이동합니다. 클럭은 모든 FF에 동시에 들어가고, 각 FF는 에지 직전의 왼쪽 값을 받습니다.
값이 한 번에 여러 칸 건너뛰지 않는 이유는 FF의 출력이 전파지연만큼 늦게 바뀌기 때문입니다. 전파지연이 홀드시간보다 길어야 다음 FF가 바뀌기 전의 값을 확실하게 읽을 수 있습니다.
N비트를 보낼 때 병렬은 클럭 1번에 선 N개, 직렬은 클럭 N번에 선 1개가 필요합니다. 병렬은 빠르고, 직렬은 경제적이고 회로가 간단합니다. 어떤 방식을 쓸지는 시스템의 응용분야와 규격에 따라 달라집니다.
