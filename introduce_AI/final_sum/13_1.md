## Loss in RNNs  `A 19:47`

- RNN을 시간 방향으로 **unfold(unroll)**하고 target sequence에 대해 loss를 계산한다(슬라이드 16). 예: `L = Σ (y_t − ŷ_t)²`
- **슬라이드 17 예시**: input `[3,1], [2,7], [4,5]` → output `0.89, 0.44, 0.92`, ground truth `y0=2, y1=4, y2=1`

```
seq-to-vec (마지막 시점만):  L = (1 − 0.92)²
seq-to-seq (모든 시점):      L = (2 − 0.89)² + (4 − 0.44)² + (1 − 0.92)²
```

- 전체 7개(window 전체)의 loss를 다 더한다는 것은 7개를 **다 예측하고 싶다**는 뜻이고, 하나만 계산하면 그 하나를 위해서 학습하겠다는 뜻이다. **loss를 바꾸면 학습 방향, 학습 목표가 달라진다.** `A 21:33`

## Backpropagation through Time (BPTT)  `A 24:36`

- 교수님: "여기부터는 펜을 내려놓고 남 얘기 듣듯이 들어도 된다." 슬라이드에도 *You don't need to understand in detail* 이라고 써 있다. 이 부분은 따로 녹화해서 올려줄 예정이다.
- hidden state: `h_t = g_h(x_t·Wx + h_{t−1}·Wh)`, output: `ŷ_t = g_y(h_t·Wy)` (bias 생략, activation function이 서로 다를 수 있음)
- `∂L/∂Wh`를 구하면 `Wh`와 관련된 것은 `h_t`이고, `h_t`는 다시 `h_{t−1}`과 `Wh`의 함수이므로 chain rule을 적용할 때마다 `Wh`가 한 번씩 더 곱해진다. `A 29:28`

```
∂L/∂Wh = Σ −2(y_t − ŷ_t) g_y′ · Wy · ∂h_t/∂Wh
       = Σ −2(y_t − ŷ_t) g_y′ · g_h′ · Wy · (∂h_{t−1}/∂Wh · Wh + h_{t−1})
       = …   ← t가 끝날 때까지 Wh가 계속 곱해짐
```

- 그래서 sequence가 길면 (슬라이드 18)
  - `Wh < 1`이면 **vanishing gradient**, `Wh > 1`이면 **exploding gradient**
  - time step마다 정보를 조금씩 잃는다 → 가장 옛날 정보를 기억하지 못한다(short-term memory problem). `A 36:15`

## LSTM (Long Short-Term Memory)  `A 37:26`

- basic RNN은 `h_{t−1}`에서 `h_t`로 넘어올 때 매번 `Wh`를 곱했고, 그래서 옛날 기억을 잃고 vanishing gradient가 생겼다.
- LSTM은 옛날 기억들 중 **어떤 것을 잘 저장해서 가져갈지**를 gate로 정한다. Gate는 "문을 열어줄래 말래"를 결정하며, sigmoid를 써서 출력이 **항상 0~1**이다. 그래서 완전히 열거나 닫는 것뿐 아니라 "절반만 기억할래" 같은 것도 가능하다. `A 41:14`
- 두 가지 state: **long-term state `c(t)`**와 **short-term state `h(t)`**

### Forget gate `f(t)`  `A 38:28`

- 현재 input `x(t)`와 이전 short-term state `h(t−1)`로 계산한다.
- 이전 시점의 long-term 기억을 **가져갈지(copy) 말지(reset to zero)**를 결정한다.
- forget gate만 있으면 이전 기억을 그냥 copy만 할 뿐 새로운 것이 추가되지 않는다 → 그래서 input gate가 필요하다.

### Input gate `i(t)`  `A 42:15`

- 현시점에서 새로 알게 된 것(`g(t)`, 새 input과 short-term state로 계산)을 forget gate를 거쳐 나온 long-term state에 **반영할지 말지**를 결정한다. 역시 sigmoid를 쓴다.
- forget gate + input gate로 **오랫동안 가져갈 memory가 무엇인지 학습**한다.

### Long-term state `c(t)`  `A 43:17`

- forget gate를 거쳐 일부 기억을 버리고(이전 것을 가져올래?), input gate가 고른 새 기억을 **덧셈**으로 추가한다(새로 추가할래?). 이 둘을 합친 것이 새로 오래 기억할 memory다.

### Output gate `o(t)`와 short-term state `h(t)`  `A 43:17`

- forget gate와 input gate를 거쳐 나온 long-term state를 이번 시점에 **얼마나 output으로 내보낼지**를 결정한다. 이것도 0~1로 얼마나 열지 정한다.
- long-term state를 copy해서 output gate로 거른 것이 short-term state `h(t)`(= 이번 시점의 output)가 된다.

### 왜 vanishing 문제가 없나  `A 45:30`

- 이전 memory를 쓸지 말지를 **gate로 control**할 뿐, 매 step마다 `W`를 곱하지 않는다. "그대로 copy할래? 얼마만큼 copy할래?"만 정하므로 gradient가 시간에 따라 곱셈으로 누적되지 않는다(슬라이드 20).

## GRU (Gated Recurrent Unit)  `A 46:40`

- 기존 RNN처럼 `h_{t−1} → h_t`로 바로 가는 것이 아니라 앞에 문(gate)을 두고 "열어줄 거야, 말 거야, 조금만 열어줄 거야"를 정한다. `r(t)`에 대한 gate가 있다는 정도만 언급됐다.
- 슬라이드 25 내용(LSTM의 단순화 버전): `c(t)`, `h(t)`를 하나의 `h(t)`로 합침, 하나의 gate controller `z(t)`가 forget gate와 input gate를 함께 제어(`1`이면 forget gate가 열리고 `0`이면 input gate가 열림), output gate 없이 `r(t)`가 이전 state 중 어느 부분을 main layer `g(t)`에 보일지 제어
- 슬라이드 26 제목에도 *will be not covered in detail* 이라고 되어 있다. (`A 48:43` 이후 전사 공백)

## Trends in AI (1): Attention  `A 50:44`

- RNN도 여전히 긴 sequence에 약하다. 특히 natural language processing(NLP)은 긴 text를 다룬다. Transformer는 NLP에서 처음 나왔지만 다른 분야에서도 뛰어난 결과를 낸다(슬라이드 29).
- **bank 예시 (슬라이드 30–31)** `A 53:44`: 그냥 "bank"만 들으면 둑인지 은행인지 알 길이 없다.
  - *"I swam across the river to get the other bank."* → `river`, `swam`을 보고 **둑**으로 이해
  - *"I walked across the road to get cash from the bank."* → `cash`를 보고 **은행**으로 이해
  - 이 단어를 이해하려면 **어디에 attend(집중)해야 하는가**에서 출발한 것이 **attention mechanism**이다. `river`는 attention을 높게, 어떤 단어는 조금 덜, 상관없는 단어는 낮게 받으면 된다. `A 58:15`
- **왜 기존 weight로는 안 되나** `A 54:51`
  - "나는 오늘 저녁으로 치킨을 먹을 거야" / "오늘 저녁으로 치킨을 먹을 거야, 난"처럼 언어는 어순이 바뀌어도 말이 된다. "have"처럼 문맥에 따라 뜻이 달라지는 단어도 있다.
  - iris 예제처럼 input이 꽃잎 너비·길이, 꽃받침 너비·길이로 **위치가 고정**되어 있으면 학습한 weight가 "첫 번째 input이 얼마나 중요한지"를 뜻한다. 순서가 바뀌면 아예 동작하지 않는다.
  - 일반 neural network는 학습이 끝나면 weight가 고정되지만, **attention은 input data에 따라 값이 달라지는 weighting factor**를 쓴다(슬라이드 32).
- 특정 위치(예: 8번째 단어)가 어디에 집중해야 하는지 계산하는 attention을 기반으로 만든 것이 **Transformer**다. 교수님은 "진짜 멋있는 모델"이라고 했다. `A 59:44`
- Transformer 아키텍처는 NLP뿐 아니라 이미지에서도 쓰인다 → **Vision Transformer(ViT)**. `A 1:00:47`

## Tokenization  `A 1:04:59`

- 지금까지 다룬 data(꽃잎 너비 등)는 숫자라 weight를 곱할 수 있었지만, "bank"에 `−0.1`을 어떻게 곱하나? → natural language를 **실수의 집합(vector)**으로 바꿔야 한다. 이것이 **tokenization**이다. Transformer의 input은 `D`차원 vector(token)들의 집합 `x1, …, xN`이고, token은 문장의 단어일 수도, 이미지의 patch일 수도 있다(슬라이드 34).
- 예: GPT-4o tokenizer로 "I love AI"를 넣으면 의미 단위로 숫자가 붙는다(시작 token은 `200264`, `user`는 `1420` 등). Llama 같은 다른 model은 tokenization 방식이 다르다. `A 1:06:02`
- **character-level tokenization**: 영어 26자를 `'a' = [1,0,…,0]`, `'z' = [0,…,0,1]`처럼 표현하는 것도 tokenization이지만, 글자 하나로는 무슨 의미인지 알 수 없다.
- 최근 architecture는 의미 있는 **단어 또는 단어 조각(word-level)** 단위로 tokenization하는 것을 선호한다. `A 1:08:09`

## 강조 사항

- BPTT 수식은 자세히 이해하지 않아도 된다. 핵심은 **`Wh`가 반복해서 곱해져서 vanishing/exploding gradient가 생긴다**는 것이다. 해당 부분은 따로 녹화 영상을 올려줄 예정이다.
- loss를 어떻게 정의하느냐(seq-to-vec vs seq-to-seq)가 **학습 목표**를 결정한다.
- LSTM의 gate 3개(forget, input, output)의 역할과, gate가 0~1 값을 낸다는 점, `W`를 곱하지 않고 copy하므로 vanishing 문제가 없다는 점
