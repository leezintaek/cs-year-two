> 지금까지 배운 fully connected network와 CNN은 한 방향으로만 흐르고(cycle 없음) input·output 길이가 고정돼 있었다. RNN은 순서가 있는 데이터(sequence, time series)를 다루기 위해 **이전 시점의 output을 현재 시점의 input으로 함께 받는** recurrent 구조를 쓰며, 계산은 `y(t) = φ(x(t)·Wx + y(t−1)·Wy + b)`다. Time window만큼 이 계산을 반복하고, 처음 시점의 이전 output은 0으로 둔다.

## 지금까지 배운 network의 특징  `A 00:00`

- 11주차 동영상 강의(CNN 활용)는 이번 주 안에 업로드 예정. 오늘 수업을 듣는 데는 지장 없음.
- Fully connected network: input → weight 곱, bias 더함 → activation → 다음 layer → … → 예측값과 ground truth로 loss 계산해 학습.
- CNN도 convolution → pooling → … → flatten → fully connected로 **순차적으로 앞으로만** 진행.
- 공통점 1: 자기 노드로 다시 돌아오는 경로, 즉 **cycle이 없다**.
- 공통점 2: **input·output 길이가 고정**이다.
  - Iris: input feature 4개 → 첫 hidden layer가 10개면 weight는 `4 × 10`. Input 4개는 바꿀 수 없다.
  - LeNet-5는 `32 × 32 × 1`만 받으므로 MNIST(`28 × 28`)는 padding 2를 넣거나 interpolation으로 키워서 맞췄다.
  - Output도 CIFAR-10은 10개, MNIST는 10개, Iris는 3개로 정해져 있다.
- 이런 데이터를 표(row = example, column = attribute)로 나타낼 수 있어서 **tabular data**라고 부른다. 그리고 input 하나를 넣으면 **한 시점에서 정답 하나**를 예측했다.

## RNN이 다루는 데이터와 응용  `A 05:25`

- RNN은 **순서가 있는 데이터(sequential / time-series data)** 학습에 유리하다.
  - 주가: 그저께, 어제, 오늘 가격 → 내일 가격
  - 자율주행의 car trajectory: 지금까지 위치 순서를 보고 다음 위치 예측
  - **NLP(Natural Language Processing, 자연어 처리)**: 언어도 단어가 나오는 순서가 있다. "나는 오늘 저녁으로 치킨을 먹을 거야"의 순서가 바뀌면 의미가 달라진다.
- 슬라이드 6의 응용 예시
  - **Image captioning**: 이미지에 "a drawing of a pink and blue pokemon"처럼 설명을 붙인다. 단어 순서가 정해져 있다. 순서를 섞으면 전혀 다른 말이 된다.
  - **Translation**: 스페인어 단어 sequence를 받아 영어 sequence("Welcome to …")를 만든다.
- Input 길이가 다양할 수도 있고(3일치 주가를 보고 다음 날 예측), output 길이가 다양할 수도 있다(고정된 이미지 하나 → 길이가 정해지지 않은 caption).
- 정리: RNN은 sequence가 어떻게 변하는지를 바탕으로 **미래를 예측**하는 network다. Sequence 길이를 2일, 10일, 20일처럼 가변적으로 다룰 수 있다는 것이 장점이며, 이를 위해 layer 안에서 **순환(cycle)**한다.

## Recurrent connection과 unfolding  `A 10:43`

- Fully connected neuron: input 전체에 weight를 곱해 더한다.
- Convolution neuron: 특정 영역에 filter(weight)를 곱해 더한다.
- Recurrent neuron: 기존처럼 `x`에 weighted sum + activation을 해서 `y`를 내는데, 여기에 **자기 output이 자기에게 돌아오는 cycle**이 추가된다. 이 cycle이 시간과 관련된 부분이다.
- 이를 시간 축으로 펼쳐 그린 것을 **unfolding**이라 한다. 시점 `t`의 neuron은 현재 input `x(t)`뿐 아니라 **이전 시점의 output `y(t−1)`도 input으로 받는다.** 그래서 시간에 따라 어떻게 변하는지를 학습할 수 있다.
- Neuron이 여러 개여도 같다. 모든 neuron이 input vector `x(t)`와 이전 시점의 output vector `y(t−1)`을 받는다.
- **예외** `A 13:52`: 첫 시점(`t = 0`)에는 이전 output이 없으므로 **일반적으로 0으로 초기화**한다.

## Recurrent neuron의 계산  `A 14:55`

- Weight가 두 종류 필요하다.
  - `Wx`: 현재 input `x(t)`에 대한 weight
  - `Wy`: 이전 시점 output `y(t−1)`에 대한 weight

```
y(t) = φ( x(t)·Wx + y(t−1)·Wy + b )
     = φ( [x(t)  y(t−1)] · W + b ),   W = [Wx ; Wy]  (세로로 이어 붙임)
```

- 두 식은 완전히 같다. `x(t)`와 `y(t−1)`을 옆으로 이어 붙이고 `Wx`, `Wy`를 세로로 이어 붙이면 곱한 결과가 같기 때문이다. 교수님은 위쪽 식(따로 곱해서 더하기)이 더 편하다고 하셨고, 편한 쪽을 쓰면 된다.
- `b`는 필요하면 넣는 bias vector, `φ`는 activation function이다. RNN에서는 **`tanh`를 많이 쓴다.** 단, 시험에서 tanh 값을 직접 구하라고 하지는 않을 것이라고 하셨다.

### Mini-batch에서의 dimension  `A 18:12`

| 기호     | 크기                    | 의미                         |
|----------|-------------------------|------------------------------|
| `X(t)`   | `m × n_inputs`          | mini-batch의 현재 시점 input |
| `Wx`     | `n_inputs × n_neurons`  | 현재 input에 대한 weight     |
| `Y(t−1)` | `m × n_neurons`         | 이전 시점 layer output       |
| `Wy`     | `n_neurons × n_neurons` | 이전 output에 대한 weight    |
| `b`      | `n_neurons`             | neuron마다 bias 하나         |

- `m`은 mini-batch의 instance 수다. Batch는 sample 여러 개를 한꺼번에 처리하는 것이다.
- 외우기보다 이렇게 이해하라고 하셨다.
  - `n_inputs`개 feature로 `n_neurons`개 output을 만들어야 하므로 `Wx`는 `n_inputs × n_neurons`다.
  - 이전 output(`n_neurons`개)이 다음 시점에도 `n_neurons`개가 되어야 하므로 `Wy`는 `n_neurons × n_neurons`다.
- `XW`, `WᵀX` 같은 transpose 표기는 정의하기 나름이니 연연하지 말라고 하셨다(자료와 다를 수 있음).

## Time window와 계산 예시  `A 23:24`

- **Time window**: sequence의 길이. "몇 개 시점을 보고 예측할래?"를 정한다. 예를 들어 3개 시점을 보고 하나를 예측한다.
- 주가 그래프에서 `3, 2, 4`라는 순서가 주어졌을 때 다음 값이 무엇일지, 즉 순서에 따라 어떻게 변하는지를 학습한다.
- Window가 3이면 `t = 0, 1, 2`에서 각각 `x(t)`와 `y(t−1)`로 `y(t)`를 구한다.

**예시 1 (슬라이드 10)** `A 25:28`: `x(0)=3, x(1)=2, x(2)=4`, `Wx = 0.5`, `Wy = 0.2`, bias 없음, window = 3

```
y(0) = tanh(3 × 0.5 + 0    × 0.2) = tanh(1.5)   ≈ 0.91   ← y(−1)은 모르므로 0
y(1) = tanh(2 × 0.5 + 0.91 × 0.2) = tanh(1.182) ≈ 0.83
y(2) = tanh(4 × 0.5 + 0.83 × 0.2) = tanh(2.166) ≈ 0.97
```

- 핵심: **같은 시점의 `x`와 이전 시점의 `y`로 계산**한다. Time window를 3번 하느냐 5번 하느냐에 따라 몇 개를 보고 몇 개를 맞출지가 정해진다.

**예시 2: input feature가 여러 개일 때 (체크인 퀴즈)** `A 28:41`

- `x(0) = [3, 1]`, `x(1) = [2, 7]`, `x(2) = [4, 5]` (시점마다 feature 2개)
- 예측하고 싶은 값은 시점마다 1개 → `Wx`는 `2 × 1` = `[0.5, −0.1]ᵀ`, `Wy`는 `1 × 1` = `[0.2]`
- Output 개수는 input feature 개수와 상관없다. 1개든 2개든 3개든 원하는 만큼 예측할 수 있다.

```
y(0) = tanh([3 1]·[0.5; −0.1] + 0 × 0.2)
     = tanh(3×0.5 + 1×(−0.1) + 0×0.2) = tanh(1.4) ≈ 0.89
```

- Dimension 확인: `(1×2)·(2×1) = 1×1`, `(1×1)·(1×1) = 1×1` → output `1×1`
- 이어 붙인 형태로 `[3 1 0] · [0.5; −0.1; 0.2]`로 계산해도 값이 같다.
- **오늘의 체크인 퀴즈**: `y(1)`, `y(2)`까지 계산해서 제출. tanh 값은 구글에 "tanh 1.2"처럼 검색하면 계산해 준다.
  - 풀이 `A 37:51`: `y(1) = tanh(2×0.5 + 7×(−0.1) + 0.89×0.2)`, `y(2)`도 같은 방식으로 `x(2)`와 `y(1)` 사용
  - 결과(12_2 슬라이드 5에서 확인): `y(0) ≈ 0.89`, `y(1) ≈ 0.44`, `y(2) ≈ 0.92`

## 강조 사항

- 첫 시점의 이전 output(`y(−1)`)은 **0**으로 둔다.
- Weight는 두 종류: 현재 input에 대한 `Wx`, 이전 output에 대한 `Wy`. Dimension은 parameter 수 계산처럼 "몇 개를 받아 몇 개를 만드나"로 이해할 것.
- RNN activation으로 `tanh`를 많이 쓰지만 **시험에서 tanh 값을 직접 구하라고 하지는 않는다.**
