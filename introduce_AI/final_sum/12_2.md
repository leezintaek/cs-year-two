> RNN의 output `Y(t)`는 `t = 0`부터의 모든 input의 함수이므로 일종의 **memory**를 가진다(memory cell). 하지만 오래된 정보일수록 weight가 여러 번 곱해져 희미해지므로 기본 cell은 짧은 pattern만 배운다. 더 일반적인 구조는 **hidden state `H(t)`가 순환**하고 output `Y(t)`는 `H(t)`에 linear layer를 한 번 더 거쳐 만든다. 주가 예측(input 4, window 7, hidden 64, output 1) 예제로 sliding window 학습, input/output sequence 유형(vec-to-seq, seq-to-vec, seq-to-seq, encoder-decoder), RNN의 장단점을 다뤘다.

## 복습: recurrent neuron 계산과 지난 퀴즈  `A 00:00`

- FC network, CNN은 input/output 모양이 고정이고 layer 1 → 2 → 3 순서로 한 방향으로만 간다(tabular data, image data).
- RNN은 시간의 순서나 말의 순서처럼 **순서가 있는 데이터**를 다룬다. 현재 input과 이전 output 둘 다에 영향을 받으므로 weight 두 개로 weighted sum을 계산한다.

```
y(t) = φ( x(t)·Wx + y(t−1)·Wy + b )
```

- **지난 체크인 퀴즈 정답(슬라이드 5)** `A 02:02`: `x(0)=[3,1], x(1)=[2,7], x(2)=[4,5]`, `Wx=[0.5, −0.1]ᵀ`, `Wy=[0.2]`, bias 없음, window = 3

```
y(0) = tanh(3×0.5 + 1×(−0.1) + 0    × 0.2) ≈ 0.89   ← y(−1) = 0
y(1) = tanh(2×0.5 + 7×(−0.1) + 0.89 × 0.2) ≈ 0.44
y(2) = tanh(4×0.5 + 5×(−0.1) + 0.44 × 0.2) ≈ 0.92
```

- 즉 input sequence `[3,1], [2,7], [4,5]` → output sequence `0.89, 0.44, 0.92`
- 지난주 휴강한 CNN 동영상 강의는 이번 주 안에 업로드 예정. 오늘 목차가 길어서 다 못 나갈 수 있고, 남은 것은 다음 주 초반에 다룬다.

## Memory cell  `A 04:08`

- `y(1)`은 `y(0)`에서, `y(2)`는 `y(1)`에서, `y(3)`은 `y(2)`에서 왔다. 따라서 `y(3)`에는 `2, 1, 0` 시점의 과거 기록이 모두 담겨 있다.

```
Y(t)   는 X(t)   와 Y(t−1) 의 함수
Y(t−1) 는 X(t−1) 와 Y(t−2) 의 함수
...
⇒ Y(t)는 X(0), X(1), …, X(t) 전부의 함수 = 일종의 memory
```

- 그래서 이 neuron을 **memory cell**이라 부른다. 시간 단계를 넘어 어떤 state를 보존하는 neural network의 부분이다. 이것이 RNN이 중요한 이유다.
- **한계: 기본 cell은 짧은 pattern만 학습한다** `A 05:10`
  - `y(3)` 입장에서 `y(2)`는 `Wy`를 한 번, `y(1)`은 두 번 거쳐 온다. 100 시점 전의 정보는 `Wy`가 100번 곱해져 온다.
  - Weight는 보통 1보다 작은 값이다. 예를 들어 `0.01`이면 100 시점 전 정보에는 `0.01¹⁰⁰`이 곱해지므로 **희미해진다.**
  - 가까운 시점의 pattern은 반영되지만 먼 시점의 pattern은 잘 반영되지 않는다.

## Cell의 hidden state  `A 07:14`

- 위 한계를 조금이나마 극복하려고 구조를 더 복잡하게 만든 것이 **hidden state** 도입이다. Input과 output 사이에 숨겨진 state를 하나 둔다.
- 기본 cell: output이 곧 state이고, **`Y`가 순환**한다.

```
H(t) = Y(t) = φ( X(t)·Wx + Y(t−1)·Wy + b )
```

- 더 복잡한 cell: **`H`가 순환**하고, `Y`는 그 시점의 `H`에 linear layer(weight 하나)를 한 번 거쳐 나온다.

```
H(t) = φ( X(t)·Wx + H(t−1)·Wh + b_h )
Y(t) = φ( H(t)·Wy + b_y )
```

- Weight 세 개의 역할: `Wx`는 input → hidden, `Wh`는 hidden → 다음 시점 hidden(순환), `Wy`는 hidden → output(linear).

## 주가 예측으로 보는 RNN 동작  `A 10:22`

### Data  `A 10:22`

- IBM의 `StockData.csv`: instance 9,400개, column 6개. 주가는 시간에 따라 변하는 데이터이므로 RNN이 적합하다.
- 날짜마다 **시가(Open), 최고가(High), 최저가(Low), 종가(Close)** 4개 값이 있다.
- 전처리: 원본 데이터가 날짜순이 아니어서 **날짜순으로 sorting**했고, 이어서 **normalization**했다.
- 목표: 오늘의 4개 값으로 **다음 날 종가(Close) 하나**를 예측 → 시점마다 **input size = 4, output size = 1**.
- RNN의 특징은 4개 → 1개를 한 번 하는 것이 아니라, **4개짜리 세트 여러 개(sequence)로 1개짜리 여러 개를 만든다**는 점이다. 몇 번 반복할지는 **time window**가 정한다.
  - Window = 3이면 4개짜리 3개로 1개짜리 3개를 예측하고, window = 10이면 10개씩이다.
  - 이 예제는 **window = 7**(7일간의 변동을 본다).

### Training / Testing: sliding window  `A 16:38`

- `x(0)`부터 `x(6)`까지 7개(각각 값 4개)가 하나의 input이다. 각 시점 `x(t)`로 **다음 시점의 종가 `x(t+1)[3]`**를 예측한다. 이것이 한 세트다.
- 다음 세트는 한 칸 밀어서 `x(1)`–`x(7)`로 `x(2)[3]`–`x(8)[3]`을 예측한다.

```
99일치로 100일째를 예측하고 싶다면
Training:  [x(0),  …, x(6)]  → [x(1)[3],  …, x(7)[3]]
           [x(1),  …, x(7)]  → [x(2)[3],  …, x(8)[3]]
           …
           [x(91), …, x(97)] → [x(92)[3], …, x(98)[3]]
Testing:   [x(92), …, x(98)] → [x(93)[3], …, x(99)[3]]
```

- 구현(슬라이드 13): `create_inout_sequences(input, tw)`가 길이 `tw`짜리 sequence와 그다음 날 종가 label 쌍을 만들고, 마지막 20개를 test set으로 나눈다.
- 전체 코드는 슬라이드의 Colab 링크(IBM tutorial을 수정한 것)에 있다. 중요한 부분은 슬라이드에 다 넣어 두었으니 **슬라이드에 있는 것만 이해해도 충분**하다고 하셨다. `A 22:52`

## Input and output sequences  `A 24:52`

전사가 많이 끊겨 있어서 슬라이드 내용으로 보충했다.

| 유형            | 관계         | 예시                           |
|-----------------|--------------|--------------------------------|
| vec-to-seq      | one-to-many  | image → caption                |
| seq-to-vec      | many-to-one  | 영화 리뷰 → 감성 점수          |
| seq-to-seq      | many-to-many | 지난 N일 주가 → 하루씩 민 주가 |
| encoder-decoder | many-to-many | 번역                           |

- **Sequence-to-vector** `A 24:52`: 여러 시점의 output 중 **마지막 하나만 궁금할 때** 쓴다. 방법은 하나, 나머지 output을 **무시**하는 것이다.
  - 예 `A 27:50`: 영화 리뷰("Parasite was very awesome")를 넣어 좋아요/싫어요 classification이나 1–5점 regression. 리뷰는 자연어이고 순서가 있으므로 sequence이고, 결과는 값 하나다.
- **Vector-to-sequence** `A 28:50`: input은 하나인데 sequence를 만들고 싶을 때. 모르는 것은 0으로 처리한다고 했으므로 첫 시점 뒤로는 input을 0으로 두는 것이 일반적이다(슬라이드에는 같은 input vector를 매 시점 반복해 넣는 방식으로 적혀 있음). 예: image captioning.
- **Encoder-decoder** `A 32:29`: seq-to-vec encoder 뒤에 vec-to-seq decoder를 붙인 구조다. 보통 seq-to-seq RNN보다 잘 된다.
  - 이유: 각 시점은 **자기 앞의 단어까지만** 알 수 있다. 하지만 언어는 문장 끝의 단어가 첫 단어 번역에 영향을 줄 수 있으므로 **말을 끝까지 들어야** 한다.
  - Input을 끝까지 읽고 이해하는 과정이 **encoder**, 다 들은 뒤 출력을 만드는 과정이 **decoder**다. 예: "It is heavily raining today" → "오늘 비가 아주 심하게 내리네요"
  - GPT, Gemini 같은 모델 이야기도 언급하셨다(확인 필요: 전사 끊김).

## Seq-to-vec architecture (주가 예측)  `A 34:40`

- 주가 예제는 7일간 4개 값이 어떻게 변하는지 보고 **마지막 날의 다음 날 종가 하나**만 맞추고 싶으므로 **seq-to-vec**이다. 앞의 output(0–5번째)은 무시하고 마지막 것만 쓴다.
- Size: input 4, window 7, output 1, **hidden 64**

```
7×4 ─(rnn)→ 7×64 ─(linear)→ 7×1   → 마지막 값만 사용
H(t) = tanh( X(t)·Wx + H(t−1)·Wh + b )
  X(t): 1×4,  Wx: 4×64,  H(t−1): 1×64,  Wh: 64×64,  H(t): 1×64
  linear: H(t) 1×64 · Wy 64×1 → 1×1
```

- PyTorch 구현(슬라이드 19)

```python
class RNN(nn.Module):
    def __init__(self, input_size=4, hidden_layer_size=64, output_size=1):
        super().__init__()
        self.hidden_layer_size = hidden_layer_size
        self.rnn = nn.RNN(input_size, hidden_layer_size)
        self.linear = nn.Linear(hidden_layer_size, output_size)

    def forward(self, input_seq):
        rnn_out, hidden_out = self.rnn(input_seq.view(len(input_seq), 1, -1))
        predictions = self.linear(rnn_out.view(len(input_seq), -1))
        return predictions[-1]      # 마지막 시점만 → seq-to-vec
```

- `nn.RNN(4, 64)`: input size 4를 hidden 64로 순환시키는 RNN, `nn.Linear(64, 1)`: hidden 64 → output 1.

## Hidden state가 있는 구조의 계산 (체크인 퀴즈)  `A 44:29`

- 구조: `x(0)` → RNN → `h(0)` → linear → `y(0)`, 그리고 `h(0)`이 다음 시점으로 전파되어 `x(1)`과 함께 `h(1)` → `y(1)`, 같은 방식으로 `h(2)` → `y(2)`. Time window = 3.
- 각 weight의 위치 `A 56:25`: input → RNN은 **`Wx`**, hidden → hidden 순환은 **`Wh`**, hidden → linear → output은 **`Wy`**

```
h(t) = tanh( x(t)·Wx + h(t−1)·Wh )      (h(−1) = 0, bias 없음)
y(t) = φ( h(t)·Wy )
```

- 예시 값(전사 기준): `x`는 지난 퀴즈와 같음(`[3,1], [2,7], [4,5]`), `Wx = [0.5, −0.1]ᵀ`, `Wh = −0.1`, `Wy = 0.2`
  - `h(1) = tanh([2 7]·[0.5; −0.1] + h(0) × (−0.1))`, 이어서 `y(1) = φ(h(1) × 0.2)`
  - (확인 필요) 전사에서는 `h(0) ≈ 0.86`이라고 했지만 위 값으로 계산하면 `tanh(1.4) ≈ 0.885`다. 실제 수업 숫자는 슬라이드/판서로 확인할 것.
- 체크인 퀴즈: 3개 시점의 `y`를 구해 제출. 수업 중에는 `y(1)`까지 제출하라고 하셨다.

## Advantages vs. drawbacks  `A 1:11:38`

| 장점                             | 단점                                 |
|----------------------------------|--------------------------------------|
| 길이에 상관없이 input 처리       | 계산이 느림                          |
| input이 길어져도 model 크기 불변 | 오래전 정보에 접근하기 어려움        |
| 과거 정보를 계산에 반영          | 현재 state에 미래 input을 반영 못 함 |
| 시간에 걸쳐 weight 공유          |                                      |

- **장점**
  1. Time window로 sequence 길이를 조절하므로 input/output 길이를 자유롭게 정할 수 있다.
  2. **Model size가 input에 따라 커지지 않는다.** 여기서 input은 input sequence의 길이로 받아들이면 된다. `Wx`를 0번째, 1번째, 2번째 시점마다 다르게 쓰지 않고 **재사용**하므로 sequence가 100개든 10,000개든 필요한 weight는 `Wx`, `Wh`, `Wy`뿐이다.
  3. 이전 시점 정보를 활용할 수 있다.
  4. 시간에 따라 **weight sharing**을 하므로 sequence가 아무리 길어져도 상관없다.
- **단점**
  1. **계산이 느리다.** 원래는 input에서 output까지 한 번이면 되는데 `y(0)`, `y(1)`, `y(2)`처럼 time window만큼 반복 계산해야 한다.
  2. **오래된 정보를 알기 어렵다.** 바로 앞 시점은 `W`가 한 번 곱해지지만 100 시점 전은 100번 곱해져서 온다.
  3. **미래 input을 고려할 수 없다.** 현재 시점에서는 이전 것만 읽을 수 있다. 이 세 번째 단점을 해결하려고 나온 것이 **encoder-decoder**다.
