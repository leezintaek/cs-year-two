## Shallow에서 deep neural network로  `A 00:57`

선형 함수(`wx + b`) 하나로는 데이터에 직선 하나밖에 맞출 수 없지만, activation function을 거친 neuron을 여러 개 쓰면 꺾인 선으로 데이터에 가깝게 근사할 수 있다. 이것이 hidden layer와 neuron이 여러 개 필요한 이유다.

**ReLU의 breakpoint** `A 01:58`

```
ReLU(x) = 0  (x ≤ 0)
          x  (x > 0)
```

- 가장 간단한 activation function인 ReLU는 입력이 0인 지점에서 꺾인다.
- Neuron 하나의 출력은 `ReLU(wx + b)`이므로 `wx + b = 0`, 즉 `x = −b/w`에서 꺾인다. (슬라이드와 수업에서는 `−w/b`로 표기했으나, `w = 1, b = −1`일 때 1에서 꺾인다는 예시와 맞는 식은 `−b/w`다.)
- 따라서 neuron마다 weight와 bias가 다르면 꺾이는 지점을 여러 개 만들 수 있다.

**예시: neuron 3개, `w = [1, 1, 1]`, `b = [−1, −2, −3]`** `A 03:15`

`y = ReLU(x − 1) + ReLU(x − 2) + ReLU(x − 3)`을 구간별로 계산하면:

| 구간          | 살아 있는 항        | `y`      |
|---------------|---------------------|----------|
| `x ≤ 1`       | 없음                | `0`      |
| `1 < x ≤ 2`   | `x − 1`             | `x − 1`  |
| `2 < x ≤ 3`   | `x − 1`, `x − 2`    | `2x − 3` |
| `x > 3`       | 세 항 모두          | `3x − 6` |

- 1, 2, 3에서 한 번씩 꺾이고, 구분되는 linear region은 4개가 된다.
- 일반화하면 neuron이 `D`개일 때 최대 `D`번 꺾을 수 있어 **최대 `D + 1`개의 linear region**을 가진다.

**Layer를 쌓으면** `A 07:59`

- 한 layer가 `D + 1`개 영역으로 나눈 것을 다음 layer가 다시 `D + 1`개로 나눌 수 있다.
- 따라서 `K`개의 hidden layer(각 `D`개 neuron)는 **최대 `(D + 1)^K`개의 linear region**을 가진다. 어디까지나 최대이며, 예를 들어 같은 breakpoint를 갖는 neuron이 있으면 그만큼 줄어든다.
- Layer가 깊을수록 복잡한 non-linear 데이터도 "꺾고 꺾고 꺾어서" 근사할 수 있으므로 deep neural network가 shallow neural network보다 복잡한 데이터에 유리하다.
- 이 공식은 input 1개, output 1개, ReLU라는 단순한 경우의 이야기다. Input이 multi-dimension이거나 다른 activation function을 쓰면 영역 수가 꼭 `D + 1`이 되지는 않는다(더 많아질 수 있음).

**Parameter 개수 (input 1개, output 1개)** `A 07:11`, `A 10:30`

- Hidden layer 1개(`D`개 neuron): input → hidden에 weight `D` + bias `D`, hidden → output에 weight `D` + bias `1` → **`3D + 1`**
- Hidden layer `K`개(각 `D`개 neuron):
  - 1번째 hidden layer: `1 × D + D`
  - 2번째 ~ `K`번째 hidden layer(`K − 1`개): 각각 `D × D + D = D(D + 1)`
  - Output layer: `D × 1 + 1`
  - 합계 **`3D + 1 + (K − 1)D(D + 1)`**

## Normalization 개요  `A 12:54`

Normalization은 값의 범위가 제각각인 것을 비슷한 범위로 맞춰 주는 것이다. Network가 너무 크거나 작은 값을 다루지 않게 하려는 목적이며, 세 가지를 다룬다.

- **Data normalization**: input data 전체에 대해
- **Batch normalization**: mini-batch에 걸쳐
- **Layer normalization**: layer 안의 neuron들에 걸쳐

## Data normalization  `A 13:47`

**왜 필요한가**

- California housing 데이터를 보면 `MedInc`는 3.8~8.3, `HouseAge`는 52, `Population`은 2401, `AveOccup`은 2.1~2.8 정도로 feature마다 범위가 크게 다르다.
- Neuron은 weighted sum을 하므로, 같은 weight 0.8을 곱해도 `2401 × 0.8`과 `6.28 × 0.8`을 더하면 작은 feature는 "더해 주나 마나"가 된다. 즉 범위가 작은 feature는 학습에 거의 반영되지 않을 수 있다.
- 그래서 모든 input feature를 비슷한 범위로 re-scale한다.
- Input data는 학습 중에 바뀌지 않으므로 **normalization은 한 번만** 하면 된다.

**Min-max normalization** `A 16:08` — 값을 0~1로 re-scale

```
x̃ᵢ = (xᵢ − x_min) / (x_max − x_min)
x_max = max(x₁, …, x_N),  x_min = min(x₁, …, x_N)
```

- 전체 범위(`x_max − x_min`) 중에서 내가 가장 작은 값으로부터 얼마나 떨어져 있는지를 비율로 나타낸다.
- 예: `1, 7, 11` → `x_max = 11`, `x_min = 1`, 7은 `(7 − 1) / (11 − 1) = 0.6`
- 검증: `x_min`을 넣으면 0, `x_max`를 넣으면 1이 된다.
- (슬라이드의 두 번째 식이 `x_max = min …`으로 되어 있는데 `x_min`의 오타다. 수업 중에도 "mean"이라고 말한 부분은 min이다.)

**Z-score normalization** `A 19:51` — 평균 0, 분산 1로 re-scale

```
x̃ᵢ = (xᵢ − μ) / σ
μ = (1/N) Σ xᵢ                    (평균)
σ = √[ (1/N) Σ (xᵢ − μ)² ]         (standard deviation; 제곱은 variance)
```

- 모든 데이터에서 평균을 빼면 평균이 0으로 옮겨지고, standard deviation으로 나누면 표준편차가 1이 된다.
- Variance는 각 점이 중심(평균)에서 떨어진 거리의 제곱을 평균 낸 것으로, 데이터가 얼마나 퍼져 있는지를 나타낸다.
- 예: `2, 4, 6` → `μ = 4`, `σ = √(8/3) ≈ 1.63`
  - 2 → `(2 − 4) / 1.63 ≈ −1.22`, 4 → `0`, 6 → `(6 − 4) / 1.63 ≈ 1.22`
  - 합이 0이므로 평균 0, 계산해 보면 표준편차도 1이다.

**Check-in quiz** `A 24:32`

Feature A = `20, 45, 30, 55, 35`에 대해 두 방법으로 normalization (첫 번째 값만 채워도 성공).

- `μ = (20 + 45 + 30 + 55 + 35) / 5 = 37`
- `σ = √[(17² + 8² + 7² + 18² + 2²) / 5] = √(730 / 5) ≈ 12.08`
- Z-score: 20 → `(20 − 37) / 12.08 ≈ −1.41`
- Min-max: `x_max = 55`, `x_min = 20`, 45 → `(45 − 20) / (55 − 20) ≈ 0.71`

**Iris 예시** `A 31:34`

Iris의 sepal length(약 4.5~8)와 sepal width(약 2~4.5)는 범위가 다르다. 두 방법으로 normalization한 그림 중

- 위쪽 그림(두 축 모두 0~1) → **min-max normalization**
- 아래쪽 그림(대략 −2~3, 평균 0 근처) → **Z-score normalization**. 그림만 보고 단정할 수는 없지만, 평균을 내면 0, 표준편차를 계산하면 1이 나온다.

## Backpropagation with gradient descent  `A 33:22`

Batch normalization이 필요한 이유는 vanishing/exploding gradient 때문이고, 이를 이해하려면 gradient가 어떻게 계산되는지 알아야 한다. ("It's time to know how gradient descent works.")

**예제 network (forward)** — hidden layer 1개, activation은 sigmoid `1 / (1 + e^(−x))`

- Input: `x₀ = 0.35`, `x₁ = 0.7`
- `z₁,₀ = 0.2 × 0.35 + 0.2 × 0.7 = 0.21`, `o₁,₀ = sigmoid(z₁,₀) = 0.552`
- `z₁,₁ = 0.3 × 0.35 + 0.3 × 0.7 = 0.315`, `o₁,₁ = sigmoid(z₁,₁) = 0.578`
- `z₂,₀ = 0.3 × 0.552 + 0.9 × 0.578 = 0.686`, `o₂,₀ = sigmoid(z₂,₀) = 0.665 = ŷ`
- Loss function: `L = (ŷ − y)²`, ground truth `y = 0.5`

**Chain rule** `A 35:39`

Loss는 weight에서 바로 나오지 않고 `weighted sum(h) → activation(g) → loss function(f)`을 차례로 거쳐 나온다.

```
L = loss(sigmoid(w₁x₁ + w₂x₂)) = f(g(h(x)))
∂L/∂w₁ = ∂L/∂o₁ × ∂o₁/∂z₁ × ∂z₁/∂w₁
```

바깥 함수부터 미분하고, 안쪽을 꺼내 또 미분하고, 꺼낼 수 있을 때까지 반복하는 것이 chain rule이다.

**알아야 할 미분** `A 39:07`

- `f(ŷ) = (ŷ − y)²` → `f′ = 2(ŷ − y)` (제곱이 앞으로 내려오고, 안쪽 `ŷ` 앞의 계수 1이 곱해짐)
- `g(z) = sigmoid(z)` → `g′(z) = g(z)(1 − g(z))` — **유도하지 말고 외우면 된다. 미분 자체를 시험에 내지는 않는다.**
- `h = o₁,₀w₂,₀,₀ + o₁,₁w₂,₁,₀` → 어떤 weight로 미분하면 그 weight에 곱해진 입력만 남는다(`ax + b`를 `x`로 미분하면 `a`가 남는 것과 같음).

**Output layer weight의 gradient** `A 40:41`

```
∂L/∂w₂,₀,₀ = ∂L/∂o₂,₀ × ∂o₂,₀/∂z₂,₀ × ∂z₂,₀/∂w₂,₀,₀
           = 2(o₂,₀ − y) × o₂,₀(1 − o₂,₀) × o₁,₀
           = 2(0.665 − 0.5) × 0.665(1 − 0.665) × 0.552
           = 0.041

∂L/∂w₂,₁,₀ = 2(o₂,₀ − y) × o₂,₀(1 − o₂,₀) × o₁,₁
           = 2(0.665 − 0.5) × 0.665(1 − 0.665) × 0.578
           = 0.042
```

**한 layer 앞의 weight gradient** `A 45:19`

Forward 순서(`weighted sum → sigmoid → weighted sum → sigmoid → loss`)를 거꾸로 따라가면 된다. 앞의 두 항은 위와 똑같고, 뒤에 항이 추가될 뿐이다.

```
∂L/∂w₁,₀,₀ = ∂L/∂o₂,₀ × ∂o₂,₀/∂z₂,₀ × ∂z₂,₀/∂o₁,₀ × ∂o₁,₀/∂z₁,₀ × ∂z₁,₀/∂w₁,₀,₀
           = 2(o₂,₀ − y) × o₂,₀(1 − o₂,₀) × w₂,₀,₀ × o₁,₀(1 − o₁,₀) × x₀
           = 2(0.665 − 0.5) × 0.665(1 − 0.665) × 0.3 × 0.552(1 − 0.552) × 0.35
           = 0.002
```

- `∂z₂,₀/∂o₁,₀ = w₂,₀,₀`, `∂z₁,₀/∂w₁,₀,₀ = x₀`
- 뒤쪽(output)의 error부터 앞쪽으로 전파되며 계산하므로 **backpropagation**이라 한다. Input layer까지 도달하면 backpropagation이 끝난다.

**Weight update (optimizer)** `A 48:53`

Backpropagation은 gradient만 계산한다. 그 gradient로 weight를 어떻게 update할지 정하는 것이 **optimizer**이고, 가장 간단한 것이 gradient descent다.

```
W := W − η · ∂L/∂W        (η: learning rate)
```

Learning rate `η = 0.01`일 때:

- `Δw₂,₀,₀ = −0.01 × 0.041 = −0.00041` → `w₂,₀,₀ = 0.3 + (−0.00041) = 0.29959`
- `Δw₁,₀,₀ = −0.01 × 0.002 = −0.00002` → `w₁,₀,₀ = 0.2 + (−0.00002) = 0.19998`

모든 weight를 이렇게 update하면 한 번의 weight update가 끝난다.

## Vanishing gradient와 exploding gradient  `A 50:05`

- 같은 network에서도 output 쪽 weight의 gradient는 0.041인데 한 layer 앞의 weight gradient는 0.002로, 앞쪽과 뒤쪽 layer의 gradient 크기가 크게 차이 난다.
- 앞으로 갈수록 chain이 길어지고 곱해지는 항이 늘어난다. 이 항들이 대부분 0.5처럼 **1보다 작으면** 곱할수록 0에 가까워져 앞쪽 layer의 gradient가 거의 사라진다 → **vanishing gradient**
- 반대로 항들이 3처럼 **1보다 크면** `3 × 3 × 3 = 27`, 계속 곱할수록 무한대로 커진다 → **exploding gradient**
- 두 문제 모두 **layer가 깊을수록 심해진다**. Shallow network에서는 3~5개 항을 곱하는 정도라 괜찮지만, deep network에서는 `sigmoid → weighted sum`이 계속 반복되기 때문이다.
- Batch normalization은 이 때문에 weight가 update될 때마다 학습 중에 반복해서 수행한다(data normalization은 한 번만).

## Batch normalization과 layer normalization  `A 53:02`

**무엇을 기준으로 normalization하는가** (mini-batch로 `N`개 데이터가 동시에 들어오면 hidden neuron마다 batch 개수만큼 activation이 나온다)

- **Batch normalization**: 한 layer 안에서 **hidden neuron 하나에 대해, mini-batch 데이터들 사이에서** `μ`, `σ`를 구해 normalization
- **Layer normalization**: **데이터 하나에 대해, 그 layer의 neuron들의 activation 사이에서** `μ`, `σ`를 구해 normalization

**식** `A 55:31` — 기본은 Z-score normalization과 같다.

```
âᵢ = (aᵢ − μ) / √(σ² + ε)
μ = (1/K) Σ aᵢ,   σ = √[ (1/K) Σ (aᵢ − μ)² ]      (K: mini-batch 크기)
```

- `ε`을 빼고 보면 `√σ² = σ`이므로 Z-score와 똑같다.
- `ε`(작은 양수)을 더하는 이유: variance가 0에 가까울 정도로 작으면 나눈 값이 엄청나게 커져 발산할 수 있으므로, 이를 막으려고 약간의 값을 넣어 준다.

**효과** `A 54:26`, `A 56:37`

Gradient가 아무리 커지거나 작아져도, 같은 layer에서 나온 값들을 비슷한 범위로 맞춰 주므로 exploding은 줄이고 vanishing은 늘려 준다. Data normalization에서 feature A, feature B의 범위를 맞춰 준 것처럼, layer마다 나오는 값들을 각각 feature처럼 보고 normalization해서 비슷한 영역에 위치하게 만드는 것이다.
