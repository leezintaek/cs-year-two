# 인공지능개론 퀴즈 출제 가이드

퀴즈를 새로 만들 때마다 이 파일을 먼저 읽고 따른다.

## 출제 규칙

- 문제는 한국어로 출제한다.
- 강의 PDF에 기반하여 문제를 출제한다. `week5/practice`의 실습 코드도 출제 근거로 쓸 수 있다.
- 문제 유형: T/F, 객관식, 단답형 주관식, 빈칸 채우는 손코딩 등
  - 코드가 포함된 모든 문제는 Python으로만 제공한다.
- 출제 범위와 문제 형식은 랜덤으로 출제한다.
- 해설은 별도의 파일을 만들어 저장한다. 정답은 해설 파일에 함께 적는다.
- 파일은 `.md`로 만든다 (VS Code 미리보기로 보면서 풀이)
- 문항 수: 50문항
- 난이도: 어렵게
- 출제 중 모르거나 고민되는 부분은 사용자에게 물어보고 진행한다.
- 파일 위치: `quiz/quiz_N.md`(문제), `quiz/quiz_N_explanation.md`(정답 + 해설)
- 참고: 강의 공지상 중간고사 범위는 Problem Solving(week2) ~ Neural Networks(week7)
