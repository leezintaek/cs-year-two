## 0. 실수하기 쉬운 것 체크리스트 (먼저 볼 것)

- [ ] **f(n)**: UCS = g, Greedy = h, A* = g + h, Weighted A* = g + W·h (W > 1)
- [ ] **Hill climbing은 경로를 기록하지 않는다** → local optimum에 갇힘
- [ ] **α-β**: MAX는 α, MIN은 β를 갱신, **α ≥ β면 prune**, α·β는 부모 → 자식으로 내려감
- [ ] **Modus Tollens**: P→Q, ¬Q ⟹ ¬P. 함정: P→Q, Q ⟹ P는 틀림
- [ ] **Bayes 분모**: P(E) = P(E|C)P(C) + P(E|¬C)P(¬C)
- [ ] **나이브 베이즈 텍스트**: 기사에 **없는** 단어는 HasWord = False 확률을 곱함
- [ ] **Viterbi**: 관측 확률은 **max 밖에서** 곱함
- [ ] **혼동 행렬**: 행 = 실제, 열 = 예측. Recall = TP/(TP+FN), Precision = TP/(TP+FP)
- [ ] **validation = 모델 선택**, test = 최종 평가
- [ ] **행렬 크기**: φ(Wx + b)에서 W는 (출력 × 입력) = m×n
- [ ] **파라미터 수** = 입력 × 출력 + 출력(bias)
- [ ] **XOR는 선형 분리 불가** → 은닉층 필요
- [ ] **ΔW = −η·∂L/∂W** (기울기 반대 방향)
- [ ] **학습 루프 순서**: `zero_grad()` → `backward()` → `step()`
- [ ] **epoch당 업데이트 수** = 훈련 데이터 수 / batch size

## 1. 탐색 (week2~3)

**탐색 문제 구성 요소**
- agent, state, initial state, action(`actions(s)`), transition model(`result(s, a)`)
- state space, action cost `c(s, a, s')`, solution(행동 순서), optimal solution(최소 비용 해)

**Uninformed vs Informed**
- Uninformed(blind): 문제 특화 지식 없음 → BFS, DFS, UCS, Iterative deepening
- Informed(heuristic): 휴리스틱 h(n) 사용 → Greedy best-first, A*, IDA*, RBFS
- h(n): n에서 목표까지 가장 싼 경로의 **예상** 비용 (예: 직선거리, 맨해튼 거리)
- BFS는 비용이 모두 같을 때만 최적, DFS는 최적 보장 X

**평가 함수 f(n)** (모두 best-first search, 우선순위 큐에서 f가 최소인 노드를 꺼냄)

| 알고리즘          | f(n)          | 특징                          |
|-------------------|---------------|-------------------------------|
| UCS               | g             | = Dijkstra, 비용 ≥ 0이면 최적 |
| Greedy best-first | h             | 빠름, 최적 보장 X             |
| A*                | g + h         | 목표 방향으로 좁게 탐색       |
| Weighted A*       | g + W·h (W>1) | 더 빠름, 최적성 희생          |

- g(n): 시작 → n까지 **실제** 비용, h(n): n → 목표까지 **예상** 비용

**UCS 절차**
1. 시작 노드를 비용 0으로 우선순위 큐에 넣는다.
2. 비용이 가장 작은 노드를 꺼낸다.
3. 이웃까지의 총 비용을 계산해 큐에 넣는다. 더 싼 경로를 찾으면 갱신한다.
4. **목표 노드가 큐에서 꺼내질 때** 종료한다 (처음 발견될 때가 아님).

**Local vs Global search**
- Local(hill climbing): 이웃으로만 이동, **경로·방문 상태를 기록하지 않음** → 메모리↓·빠름, **local optimum에 갇힘**
- Global(greedy best-first 등): 우선순위 큐로 경로와 방문/미방문 노드를 기록 → local minima 탈출 가능
- Hill climbing: 더 나은 이웃이 없으면(`value[next] ≤ value[current]`) 멈춤

**Genetic Algorithm**
- **Selection → Crossover(recombination) → Mutation**을 세대마다 반복
- TSP: 상태 = 도시 방문 순서, 거리 D가 작을수록 선택
- 로봇 내비게이션: 행동 = F/R/L 나열, **fitness = −거리 − 10 × 충돌 횟수** (덜 음수일수록 좋음)
- 교재는 local search로 분류 (global로 보기도 함)
- 큰 탐색 공간(체스 > 10⁴⁴, 바둑 > 10¹²⁰)에서 local search를 쓴다.

## 2. 게임 탐색 (week3~4)

**2인 제로섬 게임**: MAX(최대화)와 MIN(최소화)이 번갈아 둔다. 한쪽 이득 = 다른 쪽 손실.
- 구성: InitialState, ToMove(s), Actions(s), Result(s, a), IsTerminal(s), Utility(s, p)

**Minimax**
1. 게임 트리 생성 → 2. 종료 상태 도달 → 3. utility 부여
4. 위로 전파: **MAX 노드 = 자식 중 max, MIN 노드 = 자식 중 min**
5. 루트에서 가장 좋은 값을 주는 수 선택

**Alpha-Beta Pruning**
- α: MAX가 지금까지 확보한 최선(가장 큰 값), 시작 −∞
- β: MIN이 지금까지 확보한 최선(가장 작은 값), 시작 +∞
- α, β는 **부모에서 자식으로 내려보낸다**
- MAX 노드는 α를, MIN 노드는 β를 갱신
- **α ≥ β가 되면 그 노드의 남은 자식은 탐색하지 않는다**
- 결과(루트 값)는 Minimax와 같다. 탐색량만 줄어든다.

예시 (리프는 왼쪽부터 탐색)
```
            MAX
          /     \
       MIN1     MIN2
      / | \     / | \
     3 12  8   2  4  6
```
- MIN1 = min(3, 12, 8) = 3 → 루트 α = 3
- MIN2: 첫 리프 2를 보면 β = 2 → α(3) ≥ β(2) → **4, 6 prune**
- 루트 = max(3, 2) = **3**

**Heuristic alpha-beta tree search**
- Utility → **EVAL**(평가 함수), terminal test → **cutoff test**(정해진 깊이에서 멈춤)
- 좋은 EVAL: 실제 승패와 상관관계가 높고, 계산이 빠를 것
- 틱택토 예: EVAL = (O가 아직 완성 가능한 줄 수 − X가 아직 완성 가능한 줄 수) / 8
  - 예: (5 − 6) / 8 = −0.125 (8 = 가로 3 + 세로 3 + 대각 2)

**MCTS (Monte Carlo Tree Search)**
- 리프가 종료 상태가 아니면 자식을 추가해 트리를 확장
- 확장한 노드에서 게임이 끝날 때까지 **무작위로 시뮬레이션 (트리에 기록하지 않음)**
- 평균 효용 = 승률 = wins / runs

## 3. 지식과 논리 (week3~4)

**지식 기반 에이전트**: percept를 KB에 추가 → KB에 최선의 행동을 질의 → 행동했다고 KB에 알림
- 지식 표현: 논리·의미망 = **explicit**, ML/DL = **implicit**
- inference: KB로부터 새로운 사실을 이끌어내는 메커니즘

**추론 기법 4갈래**
- 논리: 사실·규칙 (빨간불이면 정지)
- 베이지안 네트워크: 불확실성 (보행자가 건널 확률 73%)
- 마르코프 모델: 시간에 따른 변화 (서 있다가 걷기 시작)
- 심층 신경망: 이미지·소리 같은 비정형 데이터

**논리적 동치**
- 함의 제거: P→Q ≡ ¬P∨Q
- 대우: P→Q ≡ ¬Q→¬P
- 쌍조건 제거: P↔Q ≡ (P→Q)∧(Q→P)
- 드모르간: ¬(P∧Q) ≡ ¬P∨¬Q, ¬(P∨Q) ≡ ¬P∧¬Q
- 이중 부정: ¬(¬P) ≡ P
- 분배: P∧(Q∨R) ≡ (P∧Q)∨(P∧R)

**추론 규칙**
- And elimination: P∧Q ⟹ P
- **Modus Ponens**: P→Q, P ⟹ Q
- **Modus Tollens**: P→Q, ¬Q ⟹ ¬P
- ⚠️ 틀린 추론: P→Q, Q ⟹ P (후건 긍정) / P→Q, ¬P ⟹ ¬Q (전건 부정)

**1차 논리 (FOL)**
- 상수 기호(객체): Harry, Gryffindor
- 술어 기호(관계): Person(x), House(x), BelongsTo(x, y)
- 정량자: ∀x Human(x) → Mortal(x)

## 4. 확률적 추론 (week4~5)

**기본 공식**
- 조건부 확률: P(a|b) = P(a∧b) / P(b)
- 곱 규칙: P(a∧b) = P(a|b)P(b) = P(b|a)P(a)
- **Bayes**: P(C|E) = P(E|C)·P(C) / P(E)
  - C = 원인(질병, 스팸), E = 관측 결과(증상, 단어)
  - 분모를 모르면 **P(E) = P(E|C)P(C) + P(E|¬C)P(¬C)**
- 논리는 0/1, 확률적 추론은 [0, 1]

**계산 예**
- 수막염: P(m|s) = 0.7 × (1/50000) / 0.01 = **0.0014**
- 백신: 접종률 0.8, 접종자 회복률 0.95, 비접종자 0.85 → 회복자가 접종자일 확률
  = 0.95×0.8 / (0.95×0.8 + 0.85×0.2) = 0.76 / 0.93 ≈ **0.82**

**나이브 베이즈**
- 가정: 원인(클래스)이 주어지면 **특징들이 서로 조건부 독립** ("naive"인 이유)
- **ŷ = argmax_k P(C_k) × Π P(xᵢ|C_k)** (분모 P(x)는 클래스마다 같아서 생략)
- 골프 예: P(Yes) ∝ 9/14 × 2/9 × 2/9 × 6/9 × 6/9 ≈ 0.0141, P(No) ∝ 5/14 × 3/5 × 2/5 × 1/5 × 2/5 ≈ 0.0068 → Yes
- 텍스트 분류: 단어 목록의 모든 단어에 대해
  - 기사에 **있는** 단어 → P(HasWord = True | C)
  - 기사에 **없는** 단어 → P(HasWord = False | C) = 1 − P(True | C)

**베이지안 네트워크**
- DAG로 인과관계 표현 (부모 = 원인, 자식 = 결과)
- **P(x₁, …, xₙ) = Π P(xᵢ | Parents(Xᵢ))** (각 노드는 부모에만 의존)
- CPT: 부모가 k개면 행 2ᵏ개, 각 행의 확률 합 = 1
- 경보 예: P(j, m, a, ¬b, ¬e) = P(j|a)P(m|a)P(a|¬b,¬e)P(¬b)P(¬e) = 0.9 × 0.7 × 0.001 × 0.999 × 0.998 ≈ **0.000628**
- 질의 확률 = (질문 조건을 만족하는 결합확률의 합) / (관측과 맞는 모든 결합확률의 합)
  - 잔디 예: P(R=T | G=T) = (0.00198 + 0.1584) / (0.00198 + 0.288 + 0.1584 + 0) ≈ **35.77%**, P(R=F | G=T) ≈ 64.23%

**마르코프 모델**
- 가정: 현재 상태는 **바로 이전 상태에만** 의존 → P(Xₜ | Xₜ₋₁)
- 전이 모델 P(Xₜ | Xₜ₋₁): 상태 → 상태
- 관측 모델 P(Eₜ | Xₜ): 상태 → 관측
- **마르코프 체인**: x⁽ᵗ⁺¹⁾ = x⁽ᵗ⁾ · P (P의 행 = 오늘, 열 = 내일)
  - 예: P = [[0.9, 0.1], [0.5, 0.5]], x⁽⁰⁾ = [1, 0] → x⁽¹⁾ = [0.9, 0.1] → x⁽²⁾ = [0.86, 0.14]
- **HMM**: 상태가 **하나의 이산 확률 변수**, 상태는 숨어 있고 관측(우산)만 보임

**Viterbi** (가장 가능성 높은 숨은 상태 순서)
- **Pₜ(j) = maxᵢ [ Pₜ₋₁(i) · P(j | i) ] · P(Uₜ | j)**
- 강의 예: 전이 T→T 0.7, T→F 0.3, F→T 0.3, F→F 0.7 / 관측 P(U|R) 0.9, P(U|¬R) 0.2, P₀ = 0.5, 0.5
  - t=1 (U=T): P₁(T) = max(0.5·0.7, 0.5·0.3)·0.9 = **0.315**, P₁(F) = max(0.5·0.3, 0.5·0.7)·0.2 = **0.07**
  - t=2 (U=T): P₂(T) = max(0.315·0.7, 0.07·0.3)·0.9 = **0.19845**, P₂(F) = max(0.315·0.3, 0.07·0.7)·0.2 = **0.0189**
- 마지막에 max를 준 이전 상태를 거꾸로 따라가면 전체 순서 (강의 예: T, T, F, T, T)

## 5. 기계학습 기초와 평가 (week5~6)

**학습 종류**
- 지도학습: 레이블 있음 → **분류**(클래스) / **회귀**(연속값)
- 비지도학습: 레이블 없음 → 대표가 **군집화(clustering)**
- 강화학습: 보상·벌을 보고 행동을 바꿈
- AI ⊃ ML ⊃ DL. 학습 = 관측 후 성능이 향상되는 것

**데이터 분할**
- train: 모델 학습 / **validation: 가장 좋은 모델 선택** / test: 최종 평가(unseen)
- Example = Instance = Sample = Data point
- 모델 성능은 **보지 못한 데이터**에서의 성능으로 판단
- Overfitting: 훈련 데이터에 지나치게 맞춤 → train 좋고 test 나쁨
- Underfitting: 패턴을 못 찾음 → 둘 다 나쁨
- 주요 과제: 데이터 부족, 낮은 품질, 과대·과소적합, 대표성 없음(outlier), 관련 없는 특징(→ feature engineering)

**특징과 레이블**
- feature = 입력 변수 (Iris 4개: 꽃받침·꽃잎 길이·너비), feature vector 예: [5.1, 3.5, 1.4, 0.2]
- label(target) = 출력 변수, 표현은 class ID(0, 1, 2) 또는 one-hot([1,0,0])
- 결정 경계: 선형 / 비선형. 임베딩 공간 = latent space (핵심 특징만 보존)
- 이진 분류(Positive 1 / Negative 0), 다중 클래스(one-hot), multi-label(여러 레이블 동시)

**분류 지표** (혼동 행렬: **행 = 실제, 열 = 예측**)

| 지표      | 식             | 기준     | 중요할 때   |
|-----------|----------------|----------|-------------|
| Accuracy  | (TP+TN) / 전체 | 전체     | 클래스 균형 |
| Recall    | TP / (TP+FN)   | 행(실제) | FN이 치명적 |
| Precision | TP / (TP+FP)   | 열(예측) | FP가 치명적 |

- 이름 읽기: 앞(True/False) = 맞았나, 뒤(Positive/Negative) = 무엇으로 예측했나
- 질병 진단처럼 **환자를 놓치면(FN) 안 되면 Recall**
- 강의 표현: Precision은 "실제 양성 샘플 수가 제한적일 때" 중요
- Error rate = 1 − accuracy
- 코로나 예: TP 700, FN 100, FP 30, TN 170 → Acc 0.87, Precision ≈ 0.959, Recall 0.875

**다중 클래스**
- Accuracy = 대각선 합 / 전체
- Macro: 클래스별 recall(행)·precision(열)을 구한 뒤 **단순 평균**
- Micro: 클래스별 TP·FN·FP를 **합친 뒤** 계산 → 단일 레이블이면 micro P = micro R = accuracy

**회귀 지표** (m = 샘플 수)
- MAE = Σ|ŷ − y| / m, MSE = Σ(ŷ − y)² / m, RMSE = √MSE
- 예: 오차 (1, −2, 3, 4, 5) → MAE = 3, MSE = 11, RMSE ≈ 3.3
- MSE·RMSE는 **큰 오차에 더 큰 벌점** (오차 하나가 100이면 MAE 22, RMSE ≈ 44.8)

**K-fold 교차 검증**
- K개 fold로 나눠 K번 학습 (매번 K−1개로 학습, 1개로 테스트) → 성능 **평균**
- 한 번만 나눌 때의 운(너무 좋거나 나쁜 결과)을 줄임. 단점: 학습을 K번 → 시간↑

**결정 트리**
- 루트에서 테스트를 따라 내려가 리프에서 결정
- 분할 기준: **Gini impurity**, information gain. 매 단계 불순도를 가장 많이 줄이는 분할 = **greedy**
- Gini = 1 − Σ pₖ² (한 클래스만 있으면 0, 2클래스 반반이면 0.5)
  - 예: (20, 20) → 0.5 / 분할 후 (13, 0) → 0, (7, 20) → 1 − (7/27)² − (20/27)² ≈ 0.384
  - 분할 후 전체 = **샘플 수 가중평균** = 13/40 × 0 + 27/40 × 0.384 ≈ 0.259
- `max_depth`가 크면 과대적합 위험

## 6. 신경망 (week6~7)

**퍼셉트론 (TLU)**
- z = xᵀw + b → 출력 = step(z)
- OR: w = (1, 1), b = −0.5 / AND: w = (1, 1), b = −1.5 (Heaviside)
- **XOR는 직선 하나로 분리 불가** → 은닉층(MLP) 필요
- 퍼셉트론은 0/1 출력(step), 뉴런은 연속값·다양한 활성 함수
- bias: 입력과 무관한 상수 오프셋 (x₀ = 1과 가중치 w₀로 표현 가능)

**행렬 크기** (입력 n개, 출력 m개)

| 방식     | 식        | X   | W   | b   | 결과 |
|----------|-----------|-----|-----|-----|------|
| 열벡터   | φ(Wx + b) | n×1 | m×n | m×1 | m×1  |
| 행벡터   | φ(XW + b) | 1×n | n×m | 1×m | 1×m  |
| 배치 s개 | φ(XW + b) | s×n | n×m | 1×m | s×m  |

- 학습 파라미터 = W, b. **한 층의 파라미터 수 = n × m + m**
  - 예: 784 → 128 → 10이면 (784×128 + 128) + (128×10 + 10) = 100,480 + 1,290 = **101,770**
- 배치에서 b는 모든 행에 같은 값이 더해짐 (broadcasting)
- 출력 뉴런: 이진 분류는 1개(threshold), 다중 분류는 클래스 수만큼(가장 큰 값 선택)
- Iris 예: z = Wx + b = [−2.24, −0.06, 2.36] → Heaviside → [0, 0, 1] → Virginica

**활성 함수**

| 함수      | 식                      | 출력 범위      |
|-----------|-------------------------|----------------|
| Heaviside | 0 (x<0), 1 (x≥0)        | {0, 1}         |
| Sigmoid   | 1 / (1 + e^(−x))        | (0, 1)         |
| tanh      | (eˣ − e⁻ˣ) / (eˣ + e⁻ˣ) | (−1, 1)        |
| ReLU      | max(0, x)               | [0, ∞)         |
| Softmax   | e^(xᵢ) / Σ e^(xⱼ)       | (0, 1), 합 = 1 |

- Heaviside는 0/1만 내서 **회귀에 못 씀**, 클래스 간 크기 차이도 구분 못함
- Softmax: 분류에서 가장 많이 씀, 출력이 확률 분포
- `argmax`는 최댓값이 여러 개면 **첫 번째 인덱스**

**손실 함수** (= error function = cost function)
- 회귀: MSE, RMSE, MSLE, MAE, **Huber loss**
- 분류: binary/categorical cross-entropy, sparse categorical cross-entropy, hinge loss, KL divergence
  - categorical = 정답이 **one-hot**, sparse = 정답이 **정수 레이블**
- 손실 함수는 평가 지표가 아니라 **파라미터 최적화의 입력**

**학습 과정**
1. 파라미터 초기화 (랜덤, 0, 또는 pretrained)
2. 반복: forward propagation → loss 계산 → backpropagation(gradient) → 파라미터 업데이트
3. 조건(예: 반복 횟수)을 만족할 때까지

- 역전파: gradient ∂L/∂W를 **출력층부터 거꾸로** 계산
- **ΔW = −η · ∂L/∂W**, W ← W + ΔW (기울기 **반대 방향**)
- learning rate η: 너무 작으면 느림, 너무 크면 최솟값을 지나쳐 발산
- optimizer: GD, SGD, AdaGrad, RMSProp, Adam

**역전파 계산** (sigmoid, L = (y − o)², bias 없음)
- 출력층: δ = 2(o − y) · o(1 − o)
- 은닉층: δⱼ = oⱼ(1 − oⱼ) · Σ (다음 층 가중치 × 다음 층 δ)
- **Δw = −η · δ(받는 뉴런) · o(보내는 뉴런)**
- o(1 − o)는 sigmoid의 미분
- 강의 예: 출력 o = 0.665, y = 0.5 → δ₂,₀ = 2 × 0.165 × 0.665 × 0.335 ≈ 0.0735
  - w₂,₀,₀: Δw = −1.0 × 0.0735 × 0.5522 ≈ −0.0406 → 0.3 − 0.0406 = **0.2594**

**Batch와 Epoch**
- epoch = 훈련 세트 **전체를 한 번** 학습
- 예: 데이터 1,000개, batch 100 → epoch당 batch 10개 → **업데이트 10번**
- full-batch: 빠르지만 메모리↑ / mini-batch(16, 32 등): 절충

**MNIST**
- 28×28 흑백 → 입력 **784**, 클래스 **10**, train 60,000 / test 10,000
- 픽셀 [0, 255] → 정규화 [0, 1]. Fashion-MNIST도 같은 형식

**표기법**
- w_{l,i,j}: (l−1)층 i번 뉴런 → l층 j번 뉴런 가중치
- b_{l,j}: l층 j번 뉴런 bias, o_{l,j}: l층 j번 뉴런 출력

**PyTorch 모델**
```python
class our_first_nn(nn.Module):
    def __init__(self):
        super().__init__()
        self.flatten = nn.Flatten()                 # 28×28 → 784
        self.hidden_layer = nn.Linear(784, 128)     # nn.Linear(in, out)
        self.sigmoid = nn.Sigmoid()
        self.output_layer = nn.Linear(128, 10)
        self.softmax = nn.Softmax(dim=1)            # 입력이 (샘플 수, 특징 수)라서 dim=1

    def forward(self, x):
        x = self.flatten(x)
        x = self.sigmoid(self.hidden_layer(x))
        return self.output_layer(x)                 # logits
```

**PyTorch 학습 / 평가**
```python
train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)    # test는 shuffle=False
for epoch in range(epochs):
    model.train()                          # 학습 모드
    for images, labels in train_loader:
        logits = model(images)             # forward
        loss = criterion(logits, labels)   # loss
        optimizer.zero_grad()              # 이전 gradient 초기화
        loss.backward()                    # backpropagation
        optimizer.step()                   # 파라미터 업데이트

model.eval()                               # 평가 모드
with torch.no_grad():                      # gradient 계산 끄기
    prediction = model(images).argmax(dim=1)
```
