## 과제 목표
사용자와 AI 봇이 번갈아 두는 틱택토 게임을 콘솔에서 구현한다. 사용자가 항상 선공('X')이고 봇은 후공('O')이다.

### 실행 흐름
1. 시작 시 봇 전략을 1~3 중에서 선택받는다.
   - (1) Minimax search
   - (2) Random
   - (3) Left-up first (비어있는 칸 중 가장 작은 번호 우선)
2. 1~9 번호가 매겨진 3x3 보드를 출력한다 (칸 배치: 1|2|3 / 4|5|6 / 7|8|9).
3. 사용자 턴 → 봇 턴을 턴이 끝날 때까지 반복한다.
4. 종료 상태에서 결과를 출력한다: 사용자 승리(-1), 봇 승리(+1), 무승부(0).

### Minimax 규칙
- 봇('O')은 점수를 최대화하려 하고, 사용자('X')는 최소화하려 한다.
- 유틸리티: 봇 승리 +1, 사용자 승리 -1, 무승부 0.
- 슬라이드의 의사코드(페이지 33)를 따른다.

### 예외 처리
- 1~9 범위를 벗어난 입력 → `Wrong number` 출력 후 재입력.
- 이미 채워진 칸 선택 → `Unavailable` 출력 후 재입력.
