# introduce_AI 학습 보조 폴더

이 폴더는 "인공지능개론" 수업을 주차(week)별로 공부하기 위한 보조 폴더다.
각 강의 PDF는 `weekN` 폴더 안에 들어있다.

## 규칙

1. **강의 요약**: 강의 PDF의 내용을 정리해 해당 `weekN` 폴더 안에 `lecture_summary` 파일로 작성한다.
2. **Q&A 누적**: 사용자가 질문하면 그때그때 답변만 하지 말고, 해당 `weekN` 폴더의 `qna` 파일에 질문과 답변을 누적해서 기입한다. (기존 내용을 덮어쓰지 말고 이어서 추가할 것)
3. **퀴즈 생성**: 사용자가 요청할 경우, 강의 내용을 바탕으로 만든 연습 문제를 해당 `weekN` 폴더의 `quiz` 파일로 작성한다.
4. **언어**: 전문 용어(기술 용어)를 제외한 모든 답변은 한국어로 작성한다.
