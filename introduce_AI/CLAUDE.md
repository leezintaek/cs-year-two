# introduce_AI 학습 보조 폴더

이 폴더는 "인공지능개론" 수업을 주차(week)별로 공부하기 위한 보조 폴더다.
각 강의 PDF는 `weekN` 폴더 안에 들어있다.

## 규칙

1. **강의 요약**: 강의 PDF의 내용을 정리해 해당 `weekN` 폴더 안에 `lecture_summary` 파일로 작성한다. 녹음 기반 요약은 `lecture-summary` 스킬로 `summaries/<강의이름>.md`에 작성하며, `lecture_summary` 파일과 별개로 관리한다.
2. **퀴즈 생성**: 사용자가 요청할 경우, 강의 내용을 바탕으로 만든 연습 문제를 해당 `weekN` 폴더의 `quiz` 파일로 작성한다.
3. **언어**: 전문 용어(기술 용어)를 제외한 모든 답변은 한국어로 작성한다.
4. **표 작성**: 표는 VS Code에서 마크다운 원문으로 볼 때 세로선(`|`)이 줄마다 맞도록 정렬한다. 각 칸을 공백으로 채워 열 너비를 맞추고, 한글 등 전각 문자는 2칸, 영문·숫자·기호는 1칸으로 계산한다. 한 줄이 너무 길어지지 않게 셀 내용은 짧게 쓰고, 긴 설명은 표 아래로 뺀다.
