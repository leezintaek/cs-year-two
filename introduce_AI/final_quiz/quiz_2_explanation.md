### Q1. 정답: F
- 첫 시점에는 이전 output이 없으므로 **0으로 초기화**한다. (12_1 "unfolding" 예외, 12_2 hidden state의 `h(−1) = 0`도 같다)

### Q2. 정답: (1) `y(0) ≈ 0.72`, `y(1) ≈ 0.06`, `y(2) ≈ 0.87`  (2) `0.87`
```
y(0) = tanh( 2×0.4    + 0×0.5    + 0.1 ) = tanh(0.9)  ≈ 0.72
y(1) = tanh( (−1)×0.4 + 0.72×0.5 + 0.1 ) = tanh(0.06) ≈ 0.06
y(2) = tanh( 3×0.4    + 0.06×0.5 + 0.1 ) = tanh(1.33) ≈ 0.87
```
- 핵심: **같은 시점의 `x`와 바로 이전 시점의 `y`**를 쓴다 (12_1 슬라이드 10 예시와 같은 방식).
- Seq-to-vec은 마지막 output만 쓰므로 `y(2) = 0.87` (12_2).
- 함정: `tanh(0.4)`, `tanh(1.2)`는 bias `0.1`을 빼먹거나 `y(t−1)` 항을 빼먹었을 때 나오는 값이다.

### Q3. 정답: 3
- `Wy`는 이전 output(`n_neurons`개)을 다시 `n_neurons`개로 만드므로 `n_neurons × n_neurons = 8 × 8`이다. Batch 크기 `m`은 weight 크기와 무관하다 (12_1 mini-batch dimension 표).
- `X(t)`: `m × n_inputs = 32 × 5`, `Wx`: `5 × 8`, `Y(t)`: `32 × 8`, `b`: 8.

### Q4. 정답: (1) `32 × 13`  (2) `13 × 8`  (3) 112
- `X(t)`(`32 × 5`)와 `Y(t−1)`(`32 × 8`)을 옆으로 이어 붙이면 `32 × 13`.
- `Wx`(`5 × 8`)와 `Wy`(`8 × 8`)를 세로로 이어 붙이면 `13 × 8`.
- Parameter: `13 × 8 + 8 = 104 + 8 = 112` (= `Wx` 40 + `Wy` 64 + `b` 8).
- 두 계산 방식은 결과가 완전히 같다 (12_1 "Recurrent neuron의 계산").

### Q5. 정답: F
- RNN은 **모든 시점에서 같은 `Wx`, `Wh`(`Wy`)를 재사용(weight sharing)**한다. Window를 늘리면 반복 계산 횟수만 늘고 parameter 수는 그대로다 (12_2 장점 2, 4).

### Q6. 정답: (1) `h(0) ≈ 0.38`, `h(1) ≈ −0.11`, `h(2) ≈ 0.78`  (2) `y(0) ≈ 0.76`, `y(1) ≈ −0.22`, `y(2) ≈ 1.56`
```
h(0) = tanh( 2×0.3 + 1×(−0.2)    + 0×0.5      ) = tanh(0.4)   ≈ 0.38
h(1) = tanh( 1×0.3 + 3×(−0.2)    + 0.38×0.5   ) = tanh(−0.11) ≈ −0.11
h(2) = tanh( 3×0.3 + (−1)×(−0.2) + (−0.11)×0.5) = tanh(1.045) ≈ 0.78

y(0) = 0.38 × 2    = 0.76
y(1) = −0.11 × 2   = −0.22
y(2) = 0.78 × 2    = 1.56
```
- 핵심: **순환하는 것은 `h`**이지 `y`가 아니다. 다음 시점에 넘기는 값은 `h(t)`이고, `y(t)`는 각 시점의 `h(t)`에 `Wy`를 곱해 따로 뽑는다 (12_2 hidden state, 체크인 퀴즈).
- 함정: `h(1)` 계산에 `y(0) = 0.76`을 넣으면 `tanh(0.08)`이 되어 틀린다. 보기에 그 값이 없는 것도 힌트.

### Q7. 정답: (1) 약 `0.30`  (2) 약 `0.19`  (3) 학습 목표(무엇을 맞추도록 학습할지)
```
seq-to-seq: (1 − 0.76)² + (0 − (−0.22))² + (2 − 1.56)²
          = 0.0576 + 0.0484 + 0.1936 = 0.2996 ≈ 0.30
seq-to-vec: (2 − 1.56)² = 0.1936 ≈ 0.19
```
- 모든 시점 loss를 더하면 "모두 맞추고 싶다", 마지막 하나만 쓰면 "그 하나를 맞추고 싶다"는 뜻이다. **Loss를 바꾸면 학습 방향과 목표가 달라진다** (13_1 Loss in RNNs, 슬라이드 17).

### Q8. 정답: 2
- `Wx`: input → hidden, `Wh`: hidden → 다음 시점 hidden(순환), `Wy`: hidden → output(linear) (12_2 `A 56:25`).
- 3: weight sharing이므로 시점마다 새로 만들지 않는다. 4: 그건 기본 cell의 `Wy` 설명이다. 5: hidden 구조에서는 `H`가 순환한다.

### Q9. 정답: (a) `input_size` (b) `hidden_layer_size` (c) `hidden_layer_size` (d) `output_size` (e) `-1`

### Q10. 정답: (1) 14  (2) `x(15)[3]`  (3) 40개
- Window 10이면 `x(5)`–`x(14)`의 10개.
- 각 시점의 정답은 하루 뒤 종가이므로 마지막 output(`x(14)`에 대한 것)의 정답은 `x(15)[3]` (12_2 sliding window, 13_1 슬라이드 14 표).
- 시작 위치 `s`에 대해 마지막 label `x(s+10)[3]`이 존재해야 하므로 `s + 10 ≤ 49` → `s = 0 … 39` → 40개.

### Q11. 정답: 2

### Q12. 정답
- 단점: ① 계산이 느림 ② 오래전 정보에 접근하기 어려움 ③ 현재 state에 미래 input을 반영하지 못함
- Encoder-decoder는 **③ 미래 input을 고려하지 못하는 단점**을 해결하려고 나왔다 (12_2 단점 3).
- Encoder: input sequence를 **끝까지 읽고 이해**한다(seq-to-vec). Decoder: 다 들은 뒤 그 정보로 output sequence를 **만든다**(vec-to-seq). 문장 끝 단어가 첫 단어 번역에 영향을 줄 수 있기 때문이다.

### Q13. 정답: F
- `y(3)`은 `x(3)`, `y(2)`의 함수이고, `y(2)`는 다시 `x(2)`, `y(1)`의 함수 … 이므로 결국 `y(3)`은 `x(0) … x(3)` **전부의 함수**다. 이것이 memory cell이라 부르는 이유다 (12_2 memory cell).

### Q14. 정답: (1) 약 `0.0010`  (2) 먼(오래된) 시점의 pattern, 즉 long-term dependency
- `0.5¹⁰ = 0.0009765… ≈ 0.0010`. 오래된 정보일수록 weight가 여러 번 곱해져 **희미해진다**.
- 그래서 기본 cell은 **짧은 pattern만 학습**한다 (12_2 memory cell 한계).

### Q15. 정답: 3
- `h_t`가 `h_{t−1}`과 `Wh`의 함수이므로 chain rule을 쓸 때마다 `Wh`가 한 번씩 더 곱해진다. `Wh < 1` → vanishing, `Wh > 1` → exploding (13_1 BPTT, 슬라이드 18).
- 2는 방향이 반대인 함정.
- BPTT 수식 자체는 "자세히 이해하지 않아도 된다"고 하셨으니 이 결론만 확실히 기억하면 된다.

### Q16. 정답
- `Wh = 0.9`: 약 `0.0052` → gradient가 0에 가까워지는 **vanishing gradient**
- `Wh = 1.1`: 약 `117.4` → gradient가 폭발하는 **exploding gradient**
- 1에서 조금만 벗어나도 길게 반복 곱하면 극단적으로 변한다는 점이 핵심이다.

### Q19. 정답: (1) T (2) F (3) T (4) T
- GRU: `c(t)`와 `h(t)`를 하나로 합침, `z(t)` 하나가 forget/input gate를 함께 제어(1이면 forget gate 열림, 0이면 input gate 열림), **output gate 없음**, 대신 `r(t)`가 이전 state 중 어느 부분을 `g(t)`에 보일지 제어 (13_1 슬라이드 25). 자세히 다루지 않는다고 하셨으므로 이 정도만 알면 충분.

### Q20. 모범 답안
- **Weight sharing**: 모든 시점에서 같은 `Wx`, `Wh`, `Wy`를 재사용한다. 그래서 sequence 길이가 아무리 길어도 필요한 weight는 이 세 개뿐이고 model size가 커지지 않는다 (12_2 장점 2, 4).
- **계산이 느림**: 같은 weight로 `y(0)`, `y(1)`, `y(2)` … 를 time window만큼 **순서대로 반복** 계산해야 한다. 이전 시점 결과가 있어야 다음 시점을 계산할 수 있기 때문이다.
- **오래된 정보에 약함**: 같은 `W`가 시점마다 곱해지므로 100 시점 전 정보에는 `W`가 100번 곱해져 희미해진다(학습 시에는 BPTT의 vanishing/exploding gradient).
- **여러 time step 예측**: 다음 값을 예측한 뒤, 그 예측값을 **실제로 일어난 것처럼 input에 추가**하고 모델을 다시 돌려 그다음 값을 예측하는 것을 반복한다. 0–5일로 6일을 예측 → 6일 예측값을 붙여 1–6일로 7일 예측 (12_2 슬라이드 21, 13_1 슬라이드 10).
